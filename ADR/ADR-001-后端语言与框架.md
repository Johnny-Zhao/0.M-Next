# ADR-001 后端语言与框架

- 状态:已采纳
- 日期:2026-06-12
- 关联章节:第3章(小内核/多引擎/插件化/异步任务)、第8章(热/温/冷路径与红线)、9.6.1(E1)、9.6.2(E2)

## 背景

平台采用"小数据内核 + 能力引擎 + 制品适配器 + 异步任务"架构。后端必须支撑:

1. 强事务的数据内核:对象/字段/关系/版本变更须在同一事务内提交主数据 + 版本记录 + event_outbox(第4章、第12章闭环链路),写入 P95≤500ms;
2. 复杂领域模型与元模型驱动(对象类型、规则 DSL、权限矩阵);
3. 大量冷路径任务执行器(全量检查、AI 编排、Word/PPT/PDF 输出、STEP/XMI/ReqIF 解析);
4. E1:linux/amd64 + linux/arm64 双架构,运行于麒麟 V10/统信 UOS;E2:全依赖可离线安装、无公网硬调用。

## 备选方案对比

| 维度                    | Java 21 + Spring Boot 3(推荐)                               | Go + Gin/Fiber        | Node.js + NestJS                       | Python + FastAPI              |
| ----------------------- | ----------------------------------------------------------- | --------------------- | -------------------------------------- | ----------------------------- |
| 复杂领域建模/事务       | 强(JPA/MyBatis、声明式事务、模块化单体成熟)                 | 中,事务样板代码多     | 中,ORM 生态较弱                        | 中                            |
| Office/工程制品解析生态 | 强(POI、批量导出、XMI/ReqIF 解析库)                         | 弱                    | 中                                     | 中(python-docx 等,但性能弱)   |
| 规则引擎/DSL            | 强(可嵌入沙箱、表达式引擎成熟)                              | 中                    | 中                                     | 中                            |
| arm64 官方支持          | OpenJDK/Temurin 官方 aarch64;另有毕昇 JDK(鲲鹏)、Dragonwell | 官方 arm64            | 官方 arm64                             | 官方 arm64                    |
| 离线依赖管理            | Maven/Gradle + Nexus 私服,锁定性好                          | go mod + GOPROXY 私服 | npm 私服,依赖树庞大、native addon 风险 | pip 私服,C 扩展轮子需逐一核查 |
| 资源占用/启动           | 较高(可用 CDS/虚拟线程缓解)                                 | 低                    | 中                                     | 中                            |
| 团队招聘(国内 ToB)      | 易                                                          | 中                    | 中                                     | 中                            |

## 决策

**Java 21(LTS)+ Spring Boot 3,数据内核与能力引擎采用模块化单体(modular monolith)分层,仿真计算与制品深解析以独立 worker 进程部署。** 与说明书附录E ADR-001 一致。

要点:启用虚拟线程承接温路径异步任务;内核模块禁止引入重任务依赖(第8.9节红线);通过 Spring Modulith 或包结构约束模块边界,后续按需拆分服务而非一开始微服务化。

## E1/E2 符合性逐项核对

| 检查项                     | 结论                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------- |
| arm64 官方二进制?          | ✅ Eclipse Temurin 21 提供官方 linux/aarch64 JDK 与多架构容器镜像;麒麟/UOS 场景可换毕昇 JDK             |
| 国内镜像源可装?            | ✅ Maven 中央仓可走阿里云镜像或 Nexus/Artifactory 私服;Spring Boot 全部依赖为纯 Java jar,无平台相关产物 |
| 无公网硬依赖?              | ✅ 运行时无外呼;构建期依赖全部可离线入私服;须在 CI 中扫描禁止 `http(s)://` 硬编码公网 URL               |
| AI 端点可配置?             | ✅ AI 调用统一走 ADR 约定的环境变量配置网关(见 ADR-007/说明书 ADR-009),不绑定供应商 SDK                 |
| 无 AWS/GCP/Azure 托管依赖? | ✅ 不使用任何云 SDK;对象存储走 S3 协议 + MinIO(ADR-006)                                                 |

## 风险与缓解

| 风险                                                   | 缓解                                                                                                                    |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| JVM 内存/启动开销高,私有化小规格环境吃紧               | 模块化单体控制进程数;G1/ZGC 调优;AppCDS;给出最小 4C8G 部署基线并纳入验收                                                |
| 龙芯 3A6000 为 LoongArch64,非 aarch64,Temurin 无官方版 | 明确 E1 一线支持 x86_64+aarch64;龙芯场景采用龙芯 JDK(LoongArch 移植版)单独适配通道,纳入兼容性测试矩阵,不作为 MVP 验收项 |
| 个别依赖含 native 库(如压缩、加密)                     | 依赖准入清单(ADR-008):新增依赖必须验证 aarch64 产物;优先纯 Java 实现                                                    |
| 模块边界腐化导致"分布式单体"                           | ArchUnit 规则守护模块依赖方向;内核 API 只暴露命令/事件接口                                                              |

## 标准对齐声明(V3.3)

- 涉及标准/事实标准:Java 21、Spring Boot 3、模块化单体工程实践。
- 采用等级:A(直接采用/兼容)用于语言运行时与框架契约;模块边界与模型驱动思想为 B(语义对齐/借鉴)。
- 边界:不因标准借鉴引入独立模型解释器、模型转换引擎或 C 级工具;新增标准相关依赖须按 ADR-009 与 ADR-008 准入。
