# 提示词(单屏深钻 · 修订):M-Next — 维度轴 = 模型上的"信息视图"叠加

> 单屏深钻,可独立使用,也可作为「表达切换台 v2」之后的追问。**桌面优先,中文,亮/暗双主题。**
> **核心隐喻(务必照此理解):像游戏《城市天际线》的"信息视图"——城市只有一座,点不同按钮,同一张城市地图被重新染色成 交通 / 污染 / 水 / 电 的热力叠加。** M-Next 的"维度轴"就是这个:**中央是一个持续存在的模型视图,切维度只是把不同的物理图层"刷"到同一个模型上。**

## 一句话目标

选中同一个工程模型,沿**维度轴**切换观察它的不同物理侧面——**模型(几何/拓扑)不变,只换叠加图层**。维度切换是**无损、瞬时**的信息视图叠加,不是换数据、不是换页面。

## ⚠️ 最重要:不要做成什么(上一版就错在这)

- **维度不是"字段卡片清单",不是表格,不是一堆数字条目。** 上一版把维度做成了"派生值卡 + 一张小图",**完全错了**。
- **维度是叠加在模型视图上的图层 + 图例 + 悬停提示。** 数据(派生值/规则)退为:**图例、悬停 tooltip、右栏一行结论**——绝不是主角。
- 中央**必须是一张真正的模型图**:二维示意图 / 三维模型 / echarts 热力图 / 等值线 / 流线,**不是字段网格**。

## 布局(模型视图占绝对主宽)

- **顶部:实体上下文 + 轴切换器**。实体名 + 代号(Mono)。三排轴,本屏只激活"维度":
  - `语言:[SysML][Modelica][Excel][3D]`、`阶段:[方案][初样][正样]` ← 次要/禁用占位,小字标注
  - `维度:[⦿能量/风][热][质量/光]` ← **激活,大而醒目**,标注"信息视图 · 无损叠加"
- **中央(占 ~70% 宽,主角):模型视图画布**。同一模型,切维度时**几何/拓扑不动,只重绘叠加图层**(热力填色 / 流线 / 等照度线 / 着色)。配**色带图例**(如 风速 0→12 m/s 蓝→红)。
- **右栏(~300px,瘦):实时结论**。当前维度一行结论 + 最糟区域 + provenance 护照(来源/新鲜度/下游)+ 规则灯。**不堆字段卡。**

## 主样例 · 房子(风 / 热 / 光)—— 最像城市天际线,务必高保真

中央 = 一张**户型平面图(SVG)或等距 3D 房屋**,房间/墙/窗位置在三个维度间**完全一致**。切维度只换叠加:

- **维度·风**:在户型上叠加 **CFD 流线 + 箭头 + 风速热力**(蓝=缓→红=强);标出"穿堂强风"通道与"滞流区";图例 = 风速色带。右栏结论:"客厅—走廊形成穿堂强风,卧室角落滞流。"
- **维度·热**:同一户型,每个房间按**温度热力填色**(蓝冷→红暖)+ 等温线;标"冷点 −2°C"。图例 = 温度色带。右栏结论:"北卧偏冷,温度裕度紧。"
- **维度·光**:同一户型,叠加**采光照度**——近窗亮(暖黄)向内渐暗,画**等照度线**;标"暗区"(无直射的北房间)。图例 = 照度色带。右栏结论:"北房间采光不足,需补光。"

> 关键效果:**同一户型,风维度看到强风通道、热维度看到冷点、光维度看到暗区**——一眼看出"同一模型的不同物理侧面",这就是维度轴/信息视图的价值。

## 副样例 · 卫星能源分系统(能量 / 热 / 质量)—— 证明同一壳跨领域

中央 = **能源分系统的二维框图(SVG:太阳阵—蓄电池—电源控制器—母线,带连线)或等距 3D**,拓扑在三维度间一致。切维度只换叠加:

- **能量**:各部件按**功率/SOC 着色**(母线红=能量余量 −4.2% 阻断),连线**粗细=功率流**;可并一张 echarts **SOC—轨道周期曲线**作副图。
- **热**:同一框图,部件按**温度热力**着色;蓄电池阴影区 −8°C 标 WARN。
- **质量**:同一框图,部件按**质量占比**着色(或 echarts 质量树图/占比条);质量余量 +5.7% 绿。

## 可用的可视化技术(请实际画出图形,不要用字段卡替代)

- **二维模型/示意图**:SVG(户型、框图、拓扑),用填色/流线/等值线做叠加;
- **图表**:**echarts**(CDN)——热力图 `heatmap`、折线(SOC)、等值线、树图/占比;
- **三维**(可选):three.js 等距模型,部件按维度着色;若不便实现,用**等距 SVG** 近似。
- 叠加图层用半透明热力 + 色带图例;**色带 + 数值 + 图标三重编码**(色彩非唯一信息载体)。

## 交互

- **切维度**:点 `能量/风·热·质量/光` → **只有叠加图层与图例重绘,模型几何不动**;无 loading(无损);轴旁"切换无损 · 信息视图"提示一闪。
- **悬停模型上的房间/部件/连线** → tooltip:该维度的值 + provenance(来源/新鲜度)。
- **点某区域** → 右栏展开 provenance 护照(上游来源·新鲜度 / 本值规则·派生 / 下游依赖);若上游过期,标琥珀"基于较旧来源,结论可能不一致"。
- **点规则灯/告警区** → 规则详情(阈值/触发)。
- 色带图例可悬停读数。

## 状态(本屏覆盖)

`default`(能量/风维度叠加) / `loading`(模型骨架,首次取几何) / `empty`(该维度无数据:"此模型未配置热维度图层") / `error`(可重试) / `recomputing`(改值后叠加重算,色带转圈) / `blocked`(某区域命中红线 → 该区域红色阴影 + 阻断标) / `stale`(叠加基于过期来源,琥珀提示)。

- 平台框架令牌(轴切换器、右栏、徽标、强调色、语义色、等宽代码字、`fx` 芯片):**由你设计,基调走现代 Office / Fluent("Office 2026"方向),详见 v2 §12**;无需固定 hex。下方物理色仅为热力叠加参考,可自调。
