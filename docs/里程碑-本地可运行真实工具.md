# 里程碑:本地可运行的真实工具(室内设计 P1 纵切真品)

> 目标:让你能在**本机浏览器**里点开**真实的** M-Next 工作台(真后端、真 CQRS、真规则引擎、真持久化),用室内设计 P1:选 profile→进工作台→画户型→派生/规则灯/风热光维度。**不是 mock,不是原型。** 完整 13 模块是后续多期路线(见 `设计稿-室内设计profile.md`);本里程碑交付可用的纵切真品。

## 为什么现在还点不出东西
- DB 启动是空的(只有迁移,无 seed);HOME 用占位项目、指向空 workspaceId;profile 目前只活在测试里。
- 前端 `packages/web` 无 `dev` 脚本、vite 无 proxy → 本地起前端连不上后端。

## 到"可点真实工具"的路径(卡序)
1. **F0**(合)→ **③ / F1**(并行)→ **D-INTERIOR** —— 插件批,装得进 profile、实例化得出工作空间。
2. **WEB-DEV**(`T-V33-WEB-DEV`):web 加 `dev` 脚本 + vite proxy 到 :8080。可与插件批并行。
3. **DEV-SEED**(`T-V33-DEV-SEED`):dev 启动自动装室内插件 + 实例化 demo 工作空间 + 画样板户型(固定 id 对齐 HOME)。依赖 F1 + D-INTERIOR。
4. 按下方 runbook 启动 → 浏览器打开即用。

> 依赖图:WEB-DEV 随时可做;DEV-SEED 等 F1+D-INTERIOR;两者齐了就能跑真实工具。

## 启动 runbook(Windows / 本机,全部就绪后)
```bat
cd /d E:\0.M-Next

:: 1. 起本地基础设施(postgres 等)
docker compose up -d

:: 2. 起后端(dev profile:连本地 postgres + 自动 seed 样板户型)
set SPRING_PROFILES_ACTIVE=dev
mvnw.cmd -pl packages/server -am spring-boot:run
::   起来后:http://localhost:8080  (看日志 "DEV SEED: ... demo workspace ready")

:: 3. 另开一个终端,起前端 dev(proxy 到 8080)
corepack pnpm install
corepack pnpm --filter @m-next/web dev
::   打开 http://localhost:5173 → HOME 点 demo 项目 → 工作台
```

## 启动后能用到的(室内 P1)
- 选 profile(室内设计)已实例化的 demo 工作空间;
- 模型树 / 户型画布 / 属性·校验 三面板(可停靠);
- 点房间改长宽/窗面积 → `area_fx`/窗地比即重算(真后端派生);
- 规则灯:采光 BLOCK、通风/窗地比/热 WARN(真规则引擎 check_result);
- 切风/热/光维度叠加(F4 注册表 + 插件注册);
- 卸载室内插件 → 风/光维度与采光/通风规则注销、数据保留(F1 withdraw)。
