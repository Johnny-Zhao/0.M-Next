# 设计稿 — 结果时序脊与动态仿真(动态/动画轨)

> 蓝本:`docs/设计-领域定制能力边界.md` §3.5 / §4。本稿把平台从"静态结构"扩成"**结构 + 观测/结果**"两条脊。
> 定位:支撑动态/动画/动态仿真——时变结果序列的存储、查询、视图时间维绑定、外部仿真适配。**纯设计;实现卡待评审后另拆。**

## 0. 一句话
平台现有模型是**静态快照**(对象+字段=某一版的值)。动态仿真意味着**随时间变化的结果序列**——这不是 DSL 能补的,是要在既有 `simulation_run` 基础上长出一条**结果时序数据脊** + **时间维视图绑定** + **L3 仿真/求解适配(FMI)**。

## 1. 现有地基(已核实,别从零起)
- **`simulation_run` 表(server V8)已存在**:`run_id, workspace_id, snapshot_id(锚定模型版本), engine_id, status, config jsonb, result jsonb, result_hash, config_hash, queued_at/started_at/completed_at, created_by, failure_reason` + 按 workspace/status 索引。
- 已是"**异步仿真作业 + 结果**"骨架:run 锚定一个 snapshot(= 这次仿真对应哪个模型版本),engine_id 标识引擎,result 现为整块 blob。
- `SimulationRun*`(server)读写;`SimulationIntegrationTest`(enqueue/drain/幂等/状态机)已绿。
- `engines/exchange/sysml/SysmlXmiCodec`(XMI 地基,跨域/标准模型导入用)。
- 快照(snapshot)/差异(diff)/血缘(lineage)读模型齐全。

## 2. 三件要新增的东西

### 2.1 结果时序数据层(新)
现 `simulation_run.result` 是整块 blob,无法按对象/字段/时刻查询、无法驱动动画。新增**细粒度结果序列**,在 run 之下:

- **`sim_result_series`**(或 `rm_result_series`,读优化):`run_id, object_id, field_code, t (double 或 timestamp), value (double/jsonb), PRIMARY KEY/索引 (run_id, object_id, field_code, t)`。
  - 由 run 完成后**批量落库**(一次 run 产出一批序列);只读消费。
  - 大数据量:按 (run_id, object_id) 分区/降采样;保留策略随 run(删 run 级联删序列)。
- **与版本/快照/血缘的关系**:序列只读、锚定 `run → snapshot → 模型版本`;不进 rm_object 热路径(那是当前态,不是历史序列)。
- **只读查询 API**(沿用 `/views/*` 只读风格):
  - `GET /workspaces/{ws}/views/sim-runs`(列 run)
  - `GET /workspaces/{ws}/views/sim-runs/{runId}/series?object&field&from&to&downsample`(按对象/字段/时间窗/降采样取序列)

### 2.2 L3 仿真适配 + FMI(计算来源)
- 计算来源:Modelica transient、状态机/活动 token、优化迭代、离散事件——**都经事件/outbox→投影异步产出**(沿用 simulation_run 作业模型),产出落 `sim_result_series`。
- **借 FMI/FMU**(Functional Mock-up Interface,模型交换 + 协同仿真标准):L3 SPI 形态——`SimulationEngineProvider`(engine_id 路由)+ FMU 导入/导出走 codec/transformation 体系。把模型打包成 FMU、耦合外部仿真器跑联合仿真。
- **铁律**:转换/求解只在异步作业里跑;**播放只读预算好的序列,绝不在帧循环现算**;实时协同仿真(FMI co-sim 流式)是更重的逃生舱,后置。

### 2.3 时间维视图绑定(新,前端)
- 在现有视图(图/平面图/矩阵/表)之上加**一层动画绑定**,而非新视图:
  - **playhead + 时间轴拖拽**;
  - **时序→视觉编码声明式绑定**:把某 (object, field) 的序列映射到 颜色/位置/大小/标签 over t。
- 例:平面图 `thermal_temp` 热力图随 transient 演化;图里 token 沿关系流动;矩阵覆盖逐格填充。
- 读 `sim-runs/{runId}/series`,**懒加载 + 降采样**;骨架预加载(视图结构小),序列按需拉。

## 3. 性能 / 复杂度护栏(守住则视图切换不被拖慢)
1. 转换/求解**永远异步**,不进同步视图/切换路径。
2. 结果序列**独立存储**,不进 rm_object 热路径;视图只读预算好的序列。
3. 时间轴播放**只读 + 降采样**,不现算;大序列服务端降采样后再传。
4. 序列查询分页/限窗;run 级保留与级联清理。

## 4. 分期
- **T1 最小可用**:单 run、单变量 transient 回放——`sim_result_series` + series 查询端点 + 一个视图的时间维绑定(如平面图热力图)。锚定现有 simulation_run。
- **T2**:多变量/多 run 对比;状态机 token 动画;降采样策略。
- **T3**:FMI 协同仿真(FMU 导入导出 + 外部求解器耦合);实时流式(重逃生舱)。

## 5. 红线
- 写入经命令/作业入口;视图只读零拷贝;**契约/迁移人工发起**(新表 `sim_result_series` 是加性迁移);仿真/转换不得进同步视图路径;序列不污染 rm_object。
