# 插件-交换适配器开发指南

## 目标

交换适配器插件负责把外部制品文本与内部 `DataSet` 互相转换。适配器只做纯解析、映射和序列化,不得写主数据、不得发命令、不得依赖 Spring/JDBC/SQL。

## 实现 SPI

实现 `com.mnext.engines.exchange.ExchangeAdapter`:

```java
public final class MyAdapter implements ExchangeAdapter {
  public String formatId() {
    return "my-format";
  }

  public String mediaType() {
    return "application/xml";
  }

  public DataSet importToDataSet(String payload, DataSet current) {
    // parse payload, map by external keys, keep current versions for existing objects
  }

  public String exportFromDataSet(String workspace, String objectType, DataSet dataSet) {
    // map DataSet to external artifact text
  }
}
```

## 注册

在插件 jar 中新增:

```text
META-INF/services/com.mnext.engines.exchange.ExchangeAdapter
```

文件内容为实现类全限定名,每行一个:

```text
com.example.exchange.MyAdapter
```

运行时 `AdapterRegistry` 通过 JDK `ServiceLoader` 发现适配器。`formatId()` 同时作为 `/exchange/{format}` 的路径参数。

## 元模型准备

导入前需在 M2 中准备对应对象类型、字段定义和关系类型。适配器只能把外部制品映射为 `DataSet`;真正回写由 server 通过 M1 命令入口完成。

## 红线

- 不在适配器中写数据库或调用命令。
- 不把外部文件作为事实源。
- 不引入第三方解析库,除非先完成 ADR/依赖准入。
- 不实现 removed 自动删除;删除策略由后续确认流处理。
