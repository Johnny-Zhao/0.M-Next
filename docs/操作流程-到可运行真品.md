# 操作流程:从当前 main → 本地可运行的室内设计 P1 真品

> 你执行。Windows / `E:\0.M-Next`,cmd。git/构建/verify/合并全在本机(沙箱碰不得 .git)。
> 验证总闸:`corepack pnpm verify`;后端跑完接 `node scripts/check-no-skipped.mjs` 守 `Skipped:0`。后端需 Java 21 + Docker。
> 关键路径(串行):**F1 → D-INTERIOR → DEV-SEED**;WEB-DEV 可立即合;③ 可后置(不挡运行)。

## 步骤 5 · 启动(三个终端)
```bat
:: 终端 A — 基础设施
cd /d E:\0.M-Next
docker compose up -d

:: 终端 B — 后端(dev:连本地 postgres + 自动 seed)
cd /d E:\0.M-Next
set SPRING_PROFILES_ACTIVE=dev
mvnw.cmd -pl packages/server -am spring-boot:run
::   等日志:"DEV SEED: ... demo workspace ready",服务在 http://localhost:8080

:: 终端 C — 前端(proxy 到 8080)
cd /d E:\0.M-Next
corepack pnpm --filter @m-next/web dev
::   打开 http://localhost:5173
```

## 步骤 6 · 验收(浏览器里)
1. HOME 出现 demo 项目 → 点进工作台,看到样板户型(模型树/画布/属性)。
2. 点暗区房间 → 属性面板 `area_fx`/窗地比派生;采光规则灯 BLOCK(红)。
3. 改某房间长/宽/窗面积 → 派生即重算、规则灯翻转。
4. 维度切换器切 光/热/风 → 房间按维度重新着色,位置不动。
5. 卸载室内插件 → 风/光维度与采光/通风规则注销、数据保留;重装恢复。
