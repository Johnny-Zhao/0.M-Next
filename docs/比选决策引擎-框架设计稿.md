# 比选/决策引擎 框架设计稿

状态:**设计稿(待落卡)**。**取代**早先的《选型推荐-设计稿》(那份是轻量"筛+排"切片,本稿升级为正式两层框架并吸收之)。蓝本:平台定位"自带 vs 插件边界"、能源/比选两域。本稿只定结构与接口,不写代码。

## 0. 一句话

**比选/推荐 = 比选模型(配置,随行业可变)+ 方法引擎(可插拔,加权和内置/MCDA 轻量/优化外挂)+ 只读排序查询。** 自带提供能力,行业差异落在配置与方法插件里。

## 1. 两层结构

### 层一:比选模型(声明式配置,profile 级,零代码)
各行业不同的部分,全部是数据:
- **指标(criteria)**:名称、类别、方向(越大越优/越小越优)、归一方式;
- **权重(weights)**:每指标权重(规则校验 ∑=100%);
- **资格/否决(eligibility)**:硬性淘汰条件(布尔表达式,复用规则 DSL);
- **评分映射**:原始值→分(归一,复用派生 + interp/lookup);
- **方法选择**:本比选模型用哪个方法引擎(默认 `weighted-sum`)。

换行业 = 换这套配置(改数据,不改代码)。承载:profile 对象/字段/关系 + 规则 + 派生;随模板(tpl-api)安装。

### 层二:方法引擎(可插拔,挂 SPI)
对"已评分的候选 × 指标 × 权重"算综合分/排序的算法:

| 方法 | 性质 | 落地 |
|---|---|---|
| `weighted-sum` 加权和 | 算术 | **内置默认**(派生/服务直接算,无需引擎) |
| `topsis` / `ahp` / `weighted-product` 等标准 MCDA | 确定性小算法、无外部依赖 | **自研轻量方法引擎**(A 类,同 interp/SOC) |
| 组合优化(多槽联合、约束下最优组合) | 重型求解 | **外挂求解器**(B 类,挂 SimulationEngine/求解 SPI,进程外) |

## 2. 方法引擎 SPI(提议)

新增一个**决策方法 SPI**(或复用 SimulationEngine 思路):
- 输入:候选集(每候选的各指标**已归一得分**)+ 指标权重/方向 + 方法参数;
- 输出:每候选综合分 + 排序(可含子分维度);
- `weighted-sum` 为内置实现;其余方法按 SPI 注册(ServiceLoader,同 SimEngineRegistry 模式)。
- 与 SimulationEngine 关系:二者都是"喂数据→算→出结果"的可插拔引擎;可共用注册/调用骨架,或并列一个 `DecisionEngine` SPI。**实现时择一,优先复用既有 Sim 骨架以省事。**

## 3. 推荐/比选流程(只读)

1. 取候选集(产品库/候选对象,读模型,分页有界);
2. 按比选模型的**评分映射**(派生/interp)算各候选各指标归一得分;
3. 按**资格/否决**(规则)过滤;
4. 调所选**方法引擎**算综合分 + 排序;
5. 返回:推荐(首位)+ 备选(次 N)+ 各维子分 + 风险标记。
- 只读(AG-101/102)、有界(AG-202/203);**推荐是读侧建议,选定走既有写命令**(CreateRelation/选型),选后既有派生/规则自动重算——读写解耦(CQRS)。

## 4. 与"自带 vs 插件边界"的对应

- **自带**:比选模型的承载机制(元模型/派生/规则/模板)、方法引擎 SPI + `weighted-sum` 默认、只读排序查询、视图/报告。
- **插件**:具体比选模型(①profile 配置,行业可变)、TOPSIS/AHP/优化方法(②引擎)、雷达/柱状对比图与录入界面(③UI)。
- 一个"比选工具产品" = ①比选 profile + (可选)②高级方法引擎 + ③UI 的插件组合。

## 5. 待拍板(多数已在前序对话定调,此处固化)

## 6. MVP 拆卡(拍板后)
- **比选 profile 种子**(配置:指标/权重/资格/评分映射/方法选择)= 一张建型 e2e 卡(纯端点,复用 tpl-api);
- **加权和方法**:MVP 直接用派生算综合分(连方法引擎都暂不需要),先把闭环跑通;
- **方法引擎 SPI + 一个 MCDA(如 TOPSIS)**:单独一张 engines 卡(纯单测,同 SOC/interp 模式,无 Docker),验证"可插拔方法";
- **只读比选查询端点**:server 卡(排序/推荐/备选/有界)。
- 顺序:profile 种子(证配置可行)→ 比选查询(加权,证闭环)→ 方法引擎+TOPSIS(证可插拔)。
