# 提示词(窄):M-Next 首页 — 登录 + 新建项目 + 配置插件

> 直接整段复制给 Claude Design。**桌面优先,中文,亮/暗双主题,令牌由你设计(现代 Microsoft Office / Fluent,"Office 2026"方向)。**
> 这是**工作台之前的入口壳**:登录 → 项目列表/新建 → 选&配插件 → 进工作台。是**标准应用页面**(不是画布),走干净的应用壳风格;凡是会随安装增多的(插件库)按"列表+搜索+分类",别平铺。

## 概念映射(必须对齐)
- **项目 = 工作空间(workspace)**:一套数据,**基于某"插件"实例化**。
- **插件 = profile / 领域模板**:一套类型/字段/关系/规则/图元库(stencil)/默认布局。例:卫星总体、室内建筑、方案比选。
- **角色 = RBAC 四档**:VIEWER < AUTHOR < REVIEWER < ADMIN。
- **后端就绪度(诚实标注)**:工作空间从模板实例化、profile/模板、RBAC 四档**已有**;**真实登录认证 / SSO / 组织 目前是占位**(现仅 actor-id),登录页与 SSO 入口请标"**待接入**",不要画成已打通。

## 关键屏(线框 → 高保真)
1. **登录页**:M-Next 标志 + `DATA HUB`;账号密码登录 + **SSO / 企业登录入口(标注"待接入")**;记住我;报错/加载态。**只设计 UI**——真实凭据由用户输入,不在设计范围;不做注册(企业内分配)。
2. **项目列表 / 着陆页**:最近项目卡片(名称 · 所属插件 · 更新时间 · 我的角色 · 告警/红线计数)+ 搜索/按插件筛选 + **「新建项目」主按钮**;**空态**(无项目 → 引导新建)。
3. **新建项目向导(分步)**:
   - 步骤1:命名 + 描述;
   - 步骤2:**选插件(profile 库)**——卡片列表(名称 + 简介 + 预览缩略 + 分类),可搜索;
   - 步骤3:基础配置(可选默认值 / 比选权重 / 邀请成员并给 RBAC 角色);
   - 完成 → 进工作台。
4. **插件 / 模板库(管理)**:已装插件列表(启用/停用、查看其类型/规则/stencil)、**安装/导入新插件**(模板导入:Visio / draw.io / 自有);**深度 profile 配置不在此屏**(跳转到"进阶作者台",本设计只到"选 + 基础配置")。

## 渐进式展开 / 状态
- 插件库随安装增长 → 列表 + 搜索 + 分类,不常驻平铺。
- 每屏覆盖:`default / loading(骨架) / empty(引导) / error(可重试) / 无权限`。

## 令牌 / 视觉(你设计)
- 现代 Office / Fluent 方向:干净明亮、柔和材质、适度圆角、留白、单强调色 + 中性灰阶;亮暗双主题。
- 与工作台(`平台UI-图元与令牌-ClaudeDesign.md`)同一套令牌,确保入口壳与工作台观感一致。

## 明确不做
- ✗ 工作台本体(画布/面板,另有设计);
- ✗ 深度 profile 作者台(类型/字段/规则编辑);
- ✗ 真实认证逻辑 / 凭据处理(只出登录 UI,SSO 标"待接入")。

## 交付
登录页 + 项目列表 + 新建向导三步 + 插件库,各高保真 + 全状态 + 令牌表(Fluent 方向),与工作台令牌一致。
