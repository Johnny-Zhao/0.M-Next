## 一、这一程做了什么

### T-V33 — 地基大批(数据中心化主链 + 多视图 + 领域插件机制)
一次性把平台从"能存模型"做到"能用":CQRS 命令链 + 事件 outbox + 读模型投影、五镜头视图(表/树/图/文档/矩阵)+ 选择联动、规则引擎 + 派生计算层 + 表达式语言、模板生命周期(发布/实例化/演化判级/撤下)、交换适配器 SPI(ReqIF/XMI/JSON/Excel)、AI 上下文执行层、RBAC MVP、比选决策(weighted/TOPSIS/AHP/WPM + 否决/风险)、领域插件机制(ProfileLoader + 声明式 manifest + 装卸),并点亮室内设计、技术方案、MBSE 三个领域样例。

这一批里最关键的架构升级是 **Profile/Stereotype 类型隔离(三阶段)**:
- **阶段一**:类型身份从 `(workspace, code)` 改为 `(workspace, template_version_id, code)`,用 PG16 `UNIQUE NULLS NOT DISTINCT`,根治多领域在共享作者空间里的 code 撞车(MBSE 的 `requirement` 撞技术方案的 `requirement`)。
- **阶段二**:多 profile 项目(`workspace_profile`)+ 映射 profile(`kind=mapping`)+ 跨 profile correspondence 关系 + 映射视图/覆盖端点。
- **阶段三**:元模型 DB 唯一约束、作者空间与 demo 解耦。
- **横切**:OCL 受限子集表达式语言接入(`lang` 缺省 m-expr,既有不变)。

### T-V34 — 两条"设计稿先行"的能力打到 T1 后端
- **结果时序脊**(`sim_result_series` V27 + 只读端点 + 时间维视图 playhead/热力动画):为"动态/动画/仿真回放"立住数据底座。
- **实例级组件复用**(`reusable_assembly` V28 + by-copy 放置 + 装配目录浏览):库复用从"模板级"下沉到"实例级"。

### T-V35 — MBSE 灯塔域做穿(从"能建模"到"能验证、能追溯")
- **C1** 演示数据加厚:1 任务 / ≥12 需求 / 通过·失败·未覆盖三态齐全。
- **C2** 裕度派生 + 覆盖规则:验证状态从"有没有测"升级到"测得过不过、裕度够不够"(声明式 manifest,零迁移)。
- **C3** 验证覆盖只读汇总端点:按需求集滚动 verified/unverified/failed + 缺口列表。
- **C4** 验证覆盖仪表 + 缺口高亮 + 追溯下钻(纯前端)。
- **C5** SysML 需求 ↔ MBSE 验证需求跨域映射:把阶段二的映射机制在真实灯塔场景上跑通,**没新造轮子**。

意义:MBSE 这条灯塔域**打穿了**,同时反向验证了"领域定制能力边界"与"跨域映射"两套机制在真实闭环里站得住。

- **收益**:能力目录从"按 name/code 过滤"升级为"按行业/专业/场景多值标签检索",是"能力市场"叙事的实质一步。
- **建议**:可发——它是契约卡里最轻的一类(纯加性、可缺省、旧前端行为不变),且直接服务平台定位。发则锁 **V29**。

### 决策 B:XMI 导入要不要扩到更完整?
- **现状**:`SysmlXmiAdapter/Codec/Mapper/Model` + ReqIf 适配器已在引擎里,带样例与交换测试 —— SysML XMI **最小子集(入向)**可用。
- **选项**:
  1. **维持现状/缓做**(建议):最小子集够当前 SysML 领域 + C5 跨域映射演示;完整 XMI(全 SysML/UML 元素、双向投影出向)是大工程,说明书列为研究级/Later,客户未拉起前性价比低。
  2. **小步扩**:只补当前灯塔/SysML 演示实际缺的元素(按需,一两张小卡),不追求全量。
  3. **做完整双向**:大投入,押到有明确客户/标准互换需求时。
- **建议**:选 1(缓做),需要时走选项 2 按演示缺口小步补。
