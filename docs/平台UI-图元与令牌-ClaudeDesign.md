> 直接整段复制给 Claude Design。**桌面优先,中文,亮/暗双主题。**
> **本任务范围极窄,务必照办:只产出"可换肤的视觉规范"——设计令牌 + 图元(节点)与连线的样式及全状态。** 不要画工作台外壳、停靠/浮动/分屏、命令面板、整屏布局、交互流程——**那些由 React Flow + dockview 这两个库提供,不需要你设计**。你的产物会被直接用作 **React Flow 自定义节点/边的视觉蓝本 + dockview 面板的换肤主题**。

## 背景(一句话)

M-Next 是一个数据驱动的可停靠制图工作台:中央是可编辑的图,**每个图元背后是一个带类型/字段/派生/规则的治理对象**。我需要你把"这个对象在图上长什么样"和"整套视觉令牌"定下来。

## 产出 1:设计令牌(你设计,Office / Fluent 方向)

基调走**现代 Microsoft Office / Fluent("Office 2026"方向)**:干净明亮、柔和材质、适度圆角、留白、单一强调色 + 成体系中性灰阶。产出一套可落 **CSS 变量**的 token:

- 色:强调色 + 中性灰阶(多档)+ **语义四态**(达标/通过、WARN 告警、BLOCK 阻断、陈旧·有损);
- 字:正文无衬线 + **代码/单位/标识符等宽**;
- 间距、圆角、阴影/材质、暗色映射。
- 约束:语义色成体系且**色彩非唯一信息载体**(配图标/形状);亮暗双主题齐全。

## 产出 2:图元(节点)视觉规范 —— 核心

"一个带类型的对象"在图上的样子(将作 React Flow 自定义节点)。一个图元含:

- **类型标识**:类型色条 / 小图标 + 代号(等宽,如 `BAT`)+ 名称;
- **1–2 个关键字段**(存储值)+ **派生值**:派生用 **`fx` 芯片 + 浅底 + "后端实时"**,与存储值区分;
- **规则灯**:BLOCK(红)/ WARN(橙)/ OK(绿),图标 + 色双编码;
- **provenance 护照**:小标——来源(工具/手填/导入/派生)· 新鲜度 · 下游依赖数;
- **连线锚点(端口)**:节点四周的连接点样式。

**全状态(每个都要出)**:默认 / 悬停 / 选中 / **recomputing(派生计算中,fx 转圈)** / **blocked(命中红线,红边/红角)** / **stale(基于陈旧来源,琥珀)** / **否决(灰 + 删除线)** / 只读 vs 可编辑。

**多类型示例**:给 `分系统 / 组件 / 接口 / 需求` 各一种外观(类型色/图标各异),证明同一规范跨类型成立。

## 产出 3:连线(边)视觉规范

关系在图上的样子(将作 React Flow 自定义边):

- **类型**(实线/虚线、粗细、箭头形)区分关系类型;**方向**;
- **状态**:active / unlinked(虚/灰);**选中**;**命中规则**(红);
- **走线**:正交(直角)与曲线两种外观各一;连线标签样式。

## 产出 4(可选,但很有用):独立小组件规范

`fx 派生芯片` / `规则灯(三态)` / `provenance 护照` / `陈旧标` —— 出成可复用小组件,供贴到任意面板(属性、校验、表)。

## 明确不做(再次强调)

- ✗ 不画工作台壳、面板停靠/浮动/分屏、标签栏(dockview 提供);
- ✗ 不画命令面板 ⌘K、整屏布局、导航、交互流程;
- ✗ 不画 3D / 文本面板内容。
- ✓ 只要:令牌表 + 图元各状态高保真 + 连线规范 +(可选)小组件。

## 交付物

1. 设计令牌表(CSS 变量,亮暗);
