# 备忘:可选插件(领域 profile)路线图

> 用户备忘(2026-06-21):后续需要一批可选插件。每个插件 = 一套 **profile**(类型/字段/关系/规则/图元库 stencil/默认布局 + 可能的引擎/适配器),走"设计稿 → 人确认契约 → 封闭卡"纪律落地。首页"插件库 / 新建项目向导"会列出这些供选。
>
> 就绪度:`◐ 部分已有`(已有后端卡/能力)/ `○ 待建`。

## 已点名的插件

| 插件 | 就绪度 | 已有基础 / 待建要点 |
|---|---|---|
| **能源分系统设计** | ◐ | 已有 `ENERGY-A 能源 profile 闭环` + `ENERGY-B SOC 算子`:太阳阵/蓄电池/母线、能量余量派生、规则校核、SOC 仿真、电池方案比选。待:前端 profile 化呈现、3D/维度叠加(能量/热/质量)。 |
| **SysML** | ◐ | 已有 `SYSML-XMI-L1 数据适配` + `SYSML-PROFILE-E2E`、ReqIF/XMI 双向**最小子集**(进+出:Class/«Block»/«requirement»/属性/Association)。**完整双向 XMI 设计稿已出**(《设计-完整双向XMI交换》,锚 SysML 1.6 + UML 2.5.1,扩元素覆盖+往返保真,待契约确认拆卡)。待:更全 SysML 子集、图元 stencil、DI 图形往返(押后)。 |
| **Modelica** | ○ | 语言轴的"方程表达",说明书列为研究级/Later。要点:图↔Modelica 方程互转、Modelica 求解/联合仿真(FMU/调度器)。**最深、最后做**,先靠入向适配,双向慢长。 |
| **室内设计(建筑)** | ○ | 我们的"房子 风/热/光"维度叠加副样例的正式落地:几何 + 多物理维度信息视图(CFD 风 / 热工 / 采光)。承载"维度轴 = 信息视图叠加"。待:几何/3D 接入、各物理维度的字段与规则、维度叠加渲染。 |

## 落地纪律
- 每个插件先出**领域设计稿**(类型/字段/关系/规则/默认视图与布局/所需引擎或适配器)→ 人确认契约(AG-301/501)→ 封闭卡发实现。
- 优先级随实际业务域定;**能源分系统、SysML 因已有基础,转 profile 成本最低**,可先做;Modelica 最后。
- 这些都属"插件可插拔"——同一底座 + 同一套工作台壳,不动内核。
