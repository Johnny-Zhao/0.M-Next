# 产品定位（v0.1 权威表述）

M-Next 是一个面向工程方案、技术说明书和系统设计的**结构化活文档工作台**。
用户用文档方式组织工程内容，用统一工程数据模型维护需求、参数、组成、关系、方案、校核和图表；系统自动生成图、表、矩阵和 Word/PDF 交付物；AI 将自然语言草稿转成可确认、可追踪、可校核的结构化工程数据。

短表述：M-Next = 工程活文档 + 轻量模型源 + 模型驱动图表 + AI 结构化入口。

- 首发场景：工程技术方案 / 技术说明书
- 首个 demo：TECHDOC_DEMO（workspace 22222222，「技术方案 Demo」）
- 首个闭环：text/data → model → visual/check/document → Word

## 两条不许越过的定位边界

1. 不降格成单纯 Word 生成器——文档背后必须是活的结构化模型；
2. 不膨胀回完整多领域 MBSE 平台——平台机制是内核手段，不是 v0.1 产品目标。

## AI 的角色

结构化入口，不是本体。AI 产出必须经变更集（SubmitAIChangeSet→人确认→ConfirmAIChangeSet，AG-106 强制）进入模型，不生成不可追踪的死图/死文。v0.1 允许假实现（机制真、模型不接）。

## Dogfood 目标（v0.1 后第一个真实用途）

用 M-Next 维护本仓库的《统一数据驱动办公平台技术说明书 V3.3》，第一个真实用户是作者本人。
