# 对标与边界（吸收心智，不正面复制）

| 对标 | 借鉴 | v0.1 不做 | 区别一句话 |
|---|---|---|---|
| 飞书/钉钉（协同文档） | 文档式组织、章节、内容块、表格、低门槛 | 实时协同、IM、组织架构、权限、审批流 | 它们是协同文档，M-Next 内容块背后是结构化工程数据 |
| Visio/Draw.io（通用绘图） | 关系图/流程图/结构图的表达心智 | 自由画布、任意拖拽、图形库、无限画布 | 它们画图形，M-Next 生成有数据来源和校核依据的工程图 |
| EA/Cameo（MBSE） | 统一模型源、需求/结构/接口追踪、多视图一致 | 完整 SysML/UAF/DoDAF、MBSE 生命周期、仿真 | 它们模型优先，M-Next 文档入口、模型内核，先服务写方案的人 |
| SysML v2/Mermaid/ECharts（文本→图） | 结构化描述到图的自动渲染 | 自创完整 DSL、替代渲染库、全图表类型 | 它们是渲染层，M-Next 是数据源+规则校核+视图编排层 |
| PicDoc 类（AI 生图） | 自然语言输入、AI 抽取、降低门槛 | 信息图美化、营销海报、不可追踪的 AI 直出图 | 它们 text→visual，M-Next text→model→visual/check/document |

判断新需求时先问：它把产品推向上表哪个"不做"象限？是 → 冻结或移路线图。
