# 后端产出审查要点（v3：仅当用户要求 Fable 审 Codex 的 Java/契约产出时使用）

> 前端不设审查——用户本人是前端 reviewer。本清单只服务后端/契约类产出。

1. 范围：改动文件 == 任务简报允许清单？lockfile/pom 有无未声明的依赖变动？
2. 架构不变量抽查（AGENTS.md）：写操作走命令入口（AG-110）；查询带 workspaceId+分页/深度（AG-202/203）；契约变更附 valid/invalid 夹具（AG-406）；测试无 sleep 等待（AG-504）。
3. 测试真伪：断言具体数值/状态而非"不抛异常"；失败路径有覆盖；Skipped:0。
4. 语义正确性（最易错，逐任务想一遍）：规则/派生的求值范围、读时求值需重读、树遍历深度与方向。
5. 结论三选一：可合 / 小修后可合（列出）/ 返工（说明原因）。
