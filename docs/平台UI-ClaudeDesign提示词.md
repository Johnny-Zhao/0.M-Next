# 提示词:统一数据驱动办公平台(M-Next)— 完整 UI 设计

> 直接复制以下全文喂给 Claude Design。

---

## 角色与任务
你是资深产品设计师。为「统一数据驱动办公平台 M-Next」设计**完整 UI**:信息架构、关键屏(线框→高保真)、组件系统、全状态、开发 handoff 规格。**桌面优先,中文(zh-CN)为主,亮/暗双主题。** 工具气质、数据优先、克制装饰。

## 产品定位(必须贯穿设计)
M-Next 是**多专业工程分析集线器(hub)**:收集各专业工具数据 → 统一建模呈现 → 做跨专业综合分析与闭环校核。它**不是单一工具,而是底座 + 可插拔领域插件(profile)**。一句话:**一份数据、多个工程镜头(树/表/图/矩阵/文档)、互引不互拷;专业求解外挂,综合与追溯在平台。**

## 核心概念(都要在 UI 体现)
- **工作空间(workspace)**:一个项目/一套数据,基于某 **profile(领域模板)** 实例化。
- **对象**:有类型、字段、关系;字段分**存储值**与**派生值(后端实时计算)**——UI 必须区分二者。
- **规则**:校核产生**告警**或**一票否决(BLOCK)**。
- **五种视图(同一份数据的只读镜头)**:树(层级)、表(列表,列含派生值+规则状态)、图(关系网络/拓扑)、矩阵(行列交叉,如候选×指标)、文档(结构化呈现)。
- **命令(CQRS)**:所有写操作经命令入口,读写分离;**改一处 → 派生/规则实时重算**。
- **联邦**:跨 profile 对应(同一实体多镜头互引)+ M2M 投影。
- **分析**:外接/内置引擎(仿真、决策方法如 TOPSIS)跑结果 → 回灌模型 → 可视化。
- **模板 / 审计 / 审批**:profile 可存模板复用;操作留痕;结果确认锁定。
- **领域工具(比选、卫星能源分系统、室内设计…)= 同底座上的 profile,套同一套 UI 壳**。

## 目标用户
1. 工程师/分析师:建模、切多镜头、跑分析、看派生与告警。
2. 评审/负责人:看结论、推荐、风险,确认出件。
3. Profile 作者/管理员(进阶):配类型/字段/规则/权重(可作二级界面)。

## 设计原则
数据优先、克制装饰;**统一壳 + 多镜头**;**闭环反馈**(改即重算、即校核);**可追溯**(每个派生值/结论可溯源:由哪条规则、哪次分析、哪份输入算出);告警用语义色;桌面高信息密度但不杂乱。

## 信息架构 / 导航壳
- **顶栏**:工作空间切换、全局搜索 + 命令面板(⌘K)、当前 profile/模式指示、用户。
- **左栏**:工作空间内导航(对象类型 / 视图 / 分析 / 报告 / 设置)。
- **主区**:当前镜头(树/表/图/矩阵/文档)或对象详情或分析运行器。
- **右栏(常驻「实时结论」)**:选中对象的派生值 + 规则告警灯 + provenance;未选中时显示工作空间级报警汇总。

## 关键界面(按优先级,出线框 + 高保真)
1. **工作台/总览**:工作空间概况、四阶段流程、报警灯、最近项、快捷入口。
2. **模型浏览器(五镜头)**:树/表/图/矩阵/文档,**一键切换、选择跨镜头联动**(选中对象在各镜头同步高亮),图镜头支持联邦对应高亮。表镜头列含派生值与规则状态。
3. **对象详情/编辑**:字段(存储 vs 派生不同样式)、关系、规则状态、历史/provenance、命令动作区。
4. **分析/方法运行器**:选引擎(仿真/决策方法)→ 配参数 → 跑 → 看结果 + 图表(曲线/雷达/柱状)→ 结果回灌模型。
5. **联邦/投影**:对应互查(此镜头对象 ↔ 彼镜头对象)、M2M 投影预览。
6. **报告/导出**:快照 → 报告预览 → 导出 docx/pdf/xlsx。
7. **领域样例「比选」**(证明"工具=profile+壳"):评分矩阵=矩阵视图;推荐+理由=分析;对比=表/雷达;权重 100% 校验条;一票否决置灰;风险面板。
8. (进阶)**Profile 作者台**:类型/字段/关系/规则/派生配置(可二级)。

## 关键交互
- 改字段/选型/权重 → 派生与规则**实时重算**(乐观更新 + 投影延迟的 recomputing/最终态);
- 规则 **BLOCK → 阻断 + 红**;告警 → 徽标 + 右栏汇总;
- **命令面板(⌘K)** 驱动写操作(创建/改/跑分析/导出);
- **选择联动**:跨镜头同步选中 + 联邦对应高亮;
- **provenance 溯源**:点派生值/结论 → 抽屉展开"由什么算的";
- **冲突**:并发编辑版本冲突对话框;
- **确认/审批**:锁定 + 留痕时间线。

## 状态(每个数据界面都要覆盖)
default / loading(骨架) / empty(引导建模) / error(可重试) / success(toast),外加 **recomputing(派生计算中)**、**blocked(规则阻断)**、conflict、offline。

## 视觉语言
专业、克制、数据优先;强层级与对比;语义色(红=阻断/风险、橙=告警、绿=通过);**派生值用区别样式**(如带 `fx` 标/斜体/浅底);亮/暗双主题;桌面优先(高密度),平板次之;中文为主、可国际化。气质参考工程/分析工具(Linear/Retool/数据建模工具的克制与密度),非营销站。

## 数据/技术约束(遵守)
- **读写分离**:视图只读;写经命令(按钮/命令面板触发),**UI 不发明新写路径**;
- 派生/规则来自后端实时计算,UI 负责呈现 + loading;
- 已有前端**视图 SDK(树/表/图/矩阵/文档)**与 REST(命令 / 视图 / 推荐 / 派生 / 规则 / 分析)——设计须可落到这套之上;
- **图表(曲线/雷达/柱状)、附件上传**为新增前端能力。

## 可访问性 & 响应式
键盘可达(尤其表/矩阵单元格);色彩非唯一信息载体(告警/否决配图标);对比度 WCAG AA;桌面优先,关键页响应式收窄。

## 交付物
1. 信息架构图 + 导航壳;
2. 设计语言/token(色/字/间距/语义色/暗色);
3. 组件库(表、图、矩阵、树、文档、卡、徽标、**派生值芯片**、**provenance 抽屉**、命令面板、状态占位、图表、权重校验条、风险面板);
4. 关键屏高保真:总览、五镜头、对象详情、分析运行器、比选样例、报告导出;
5. 全状态规格(见「状态」);
6. 开发 handoff(对接视图 SDK + 命令/查询 API)。
