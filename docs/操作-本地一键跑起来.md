# 本地把 M-Next 跑起来(dev,看到样板户型)

> 目标:三个窗口,登录后点"技术方案A",画布出现 6 个房间(带红黄绿规则灯)。
> 经验是踩坑换来的,严格按顺序来。

## 一次性前提
- Docker Desktop 已安装并打开(右下角图标变绿)。
- 已 `node scripts/run-maven.mjs -DskipTests package` 打过包(改了后端代码才需重打)。

## 首选:一键起停

### 启动
```bat
cd /d E:\0.M-Next
corepack pnpm dev:up
```
脚本会依次执行:
- `docker compose up -d`,并等待 postgres healthy。
- 清理占用 8080 的旧 Java 后端。
- 后台启动 dev 后端,日志写入 `logs/server.log`,PID 写入 `.dev/server.pid`。
- 等 `DEV SEED: interior-design installed, demo workspace 11111111-... ready` 出现后,在当前窗口启动前端。

看到 Vite 打印 `Local: http://localhost:5173/` 后打开浏览器。

### 停止
```bat
cd /d E:\0.M-Next
corepack pnpm dev:down
```
脚本会停止记录的后端进程、清理占用 8080 的残留 Java,并执行 `docker compose stop`。

## 兜底:手动启动顺序(三个窗口,别乱序)

### 窗口 1 — 基础设施(postgres / rabbitmq 等)
```bat
cd /d E:\0.M-Next
docker compose up -d
```
确认:`docker ps` 里有 `postgres:16-alpine ... Up (healthy)`、`rabbitmq ... Up`。**这俩没起来,后端必失败。**

### 窗口 2 — 后端(dev 档,自动种户型)
**手敲,别粘贴**(粘贴易混入隐藏字符,会报 `Unable to access jarfile ...^A`):
```
cd /d E:\0.M-Next
set SPRING_PROFILES_ACTIVE=dev
java -jar packages\server\target\server-0.1.0-SNAPSHOT.jar
```
看到这两行就绪:
- `Started MNextApplication`
- `DEV SEED: interior-design installed, demo workspace 11111111-... ready`

**这个窗口全程别关。** 关了后端 = 前端所有请求失败(画布空 / 500)。

### 窗口 3 — 前端
```bat
cd /d E:\0.M-Next
corepack pnpm --filter @m-next/web dev
```
等它打印 `Local: http://localhost:5173/`。

## 打开
浏览器开 **`http://localhost:5173`**(**不是 8080**;8080 是后端 jar 里的旧打包页,样式/数据都不对)。
登录(账号随意,默认 demo-actor)→ 点 **"技术方案A"** → 画布出现 6 个房间:
- 🟢 客厅 / 厨房 / 卫生间 OK　🟡 主卧 / 西晒书房 WARN　🔴 暗次卧 BLOCK

## 改了代码怎么办
- **改后端**(Java):窗口 2 Ctrl+C 停 → 重新 `node scripts/run-maven.mjs -DskipTests package` → 重启窗口 2。
- **改前端**(ts/tsx/css):一般热更新自动生效;若不生效,**整个关掉窗口 3 再重开**(git 切分支/合并后,vite 常需重启才认新文件)。改完浏览器 **Ctrl+Shift+R** 硬刷新。

## 常见坑速查
| 症状 | 原因 | 处理 |
|---|---|---|
| `Unable to access jarfile ...^A` | 命令尾混入隐藏字符 | 手敲那两行,别粘贴 |
| 后端 `Connection to localhost:5432 refused` | postgres 没起 | 先 `docker compose up -d` |
| 画布空 / 全是 500 | 后端窗口被关了 | 重启窗口 2,别关 |
| 页面卡死 / 错误数狂涨 | 已修(onError 死循环) | 确认在最新 main |
| `fetch ... Illegal invocation` | 已修(fetch 绑定) | 确认在最新 main |
| 样式还是深色旧样 | 看的是 8080 或 vite 没重启 | 用 5173 + 重启窗口 3 + 硬刷新 |
| 浏览器插件弹窗(翻译/AI)干扰输入 | 插件注入页面 | 用无痕窗口(Ctrl+Shift+N)开 5173 |
