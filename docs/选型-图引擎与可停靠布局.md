# 选型:图编辑引擎 + 可停靠布局库(地基)

> 为「M-Next 制图工作台」选前端中央件。约束:**React 18 / Vite / TS**;需要 **可编辑图(图=治理模型视图)+ 2D 工程图 + 3D 面板 + 文本(Mermaid)+ 可停靠面板**;受 **AG-502 依赖与许可红线**(新依赖须人评审,偏好宽松许可 MIT/Apache,商业/受限许可要走采购与法务)。
> 许可证与定价随时会变,以下为**截至 2026 年中**按各家官方/主源查到的,采购前请以官网为准。

## 1. 图编辑引擎对比

| 引擎 | 许可证 | 费用 | React/TS | 能力定位 | 维护/成熟度 | 对 M-Next 的适配 |
|---|---|---|---|---|---|---|
| **React Flow（@xyflow/react）** | **MIT** | 免费(Pro 订阅仅含示例/支持,可选) | React 原生,TS | 节点+连线图(拓扑/框图/流程),高度可定制 | 活跃、社区大 | **★ 最易"图=模型":节点=对象、边=关系,绑定数据模型最顺;改即重算反馈好做** |
| **maxGraph（@maxgraph/core）** | **Apache-2.0** | 免费 | TS(非 React 原生,需手动集成) | mxGraph(draw.io 引擎)正统继承,Visio 级:stencil、正交布线、泳道 | 活跃但**仍 0.x(v0.22)**,社区较小 | 通用制图最强;代价是成熟度(0.x)与 React 集成要自己包 |
| **JointJS(开源核)** | **MPL-2.0**(文件级 copyleft) | 核免费;**JointJS+ 约 $3,420/开发者**(永久,2026-01) | 框架无关,可配 React | 工程图强;高级件(stencil 等)在 JointJS+ | 商业团队维护,稳 | 中间路线:核够用就免费;要高级件再买 JointJS+ |
| **GoJS** | **商业**(无免费档) | **约 $3,995/开发者**起;**按应用/按域名另收**,较受限 | 有 gojs-react | 复杂工程图能力最强 | 商业团队,成熟 | 能力天花板高,但**许可最贵最受限**,与开放代码库不契合 |
| **tldraw** | **源可见(非 OSI)** | 开发免费;**生产需许可证(license key)**;商业 **$6,000/年/团队**;hobby 档强制水印 | React 原生 | 无限画布/白板手感 | 活跃 | 白板气质强、工程精度弱;**许可强制 + 年费**,治理上麻烦 |
| Excalidraw | MIT | 免费 | React | 手绘风白板 | 活跃 | 手绘美学,不适合工程精度 |

**3D 面板(独立于上)**:**three.js(MIT)**,配 react-three-fiber 包成 React 组件。
**文本面板**:**Mermaid(MIT)** 做文本→图渲染;图→文本与 AI 双向自建。

## 3. 许可红线(AG-502)视角

- **完全宽松、无忧**:React Flow(MIT)、maxGraph(Apache-2.0)、dockview(MIT)、three.js(MIT)、Mermaid(MIT)。→ 直接用,只走常规依赖登记。
- **需注意**:JointJS 核 **MPL-2.0** 是**文件级 copyleft**——只要不改它的源文件、仅作依赖引用,你的应用可闭源;但若改了 JointJS 的文件需开放那些文件。可接受,但要记一笔。
- **要走采购+法务**:GoJS、JointJS+、tldraw 商业档——有年费/永久费、按开发者/应用/域名计,且与"开放、可治理代码库"的气质相左。**不建议作为起步地基**,留作能力不够时的付费升级项。

---

## 4. 建议(分阶段,先免费宽松、后按需升级)

**P1 起步组合(全 MIT/Apache,React 原生,零许可摩擦,最快可操作):**

> **dockview(停靠)+ React Flow(2D 图)+ three.js(3D 面板)+ Mermaid(文本)**

理由:
- 全部宽松许可,AG-502 无忧,不必先花钱、先签合同;
- React Flow 的"节点=对象、边=关系"模型,**与"图=治理模型视图、画=发命令"几乎天作之合**,改即重算、派生/规则叠加都好落;
- dockview 的浮动/弹窗/分屏,正好实现"一切皆可移动浮动面板 + 2D/3D/文本多视图并存";
- three.js/Mermaid 各自成面板,互不耦合。

**何时升级:**
- 若图需求超出"节点+连线"、要 **Visio 级自由绘制 / stencil / 正交布线** → 评估 **maxGraph**(Apache,免费,但 0.x 成熟度与 React 集成成本);
- 若要**工程图能力天花板**且有预算 → **JointJS+**(中等价、许可较友好)优先于 **GoJS**(最强但最贵最受限)。

**先别做的事:** 不要一上来就上 GoJS / tldraw 商业档——在验证产品形态前锁定年费与受限许可,风险高、且踩 AG-502。

## 4.5 自主可控视角(**优先采纳,覆盖 §4**)

**自主可控的本质** = 你掌握**源码与构建链**、**无外部 kill-switch / license 服务器**、能**独立(离线)维护**、不被外商单方面卡断。据此:

**直接排除(与自主可控冲突):**
- **tldraw** —— 生产靠 **license key + 技术措施远程校验/检测部署环境/强制水印**,等于把开关交给外商,**首先出局**。
- **GoJS / JointJS+** —— 外商商业闭源/受限授权,按开发者·应用·域名计费,**供应链可被卡**,不符。

**满足"可控"的前提** = 宽松开源(MIT/Apache)+ **vendor 进私有仓、锁版本、可离线构建** + 保留 fork 自维护能力。下列均满足:

**国产开源(信创/国产化首选):**

| 库 | 出品 | 许可 | 定位 | 适配 |
|---|---|---|---|---|
| **AntV X6** | 蚂蚁集团 | **MIT** | **图编辑引擎**(DAG/ER/流程/框图,SVG+HTML,节点高度可定制) | **★ 国产 + "图=可编辑模型视图"专精,首选 2D 引擎** |
| **LogicFlow** | 滴滴 | **Apache-2.0** | 流程图编辑框架,业务自定义强、插件化 | 备选 2D,偏流程/工作流 |
| **AntV G6** | 蚂蚁集团 | MIT | 大规模关系图**可视化**(偏只读分析) | 大图/拓扑分析面板可选 |

> X6 维护活跃度社区有过疑虑(官方称继续维护、备 2.0);但**开源 + 可 fork 自维护**,自主可控反而不依赖上游节奏。

**基础层(docking / 3D / 文本)国产替代较弱**,用宽松开源 + vendor 自维护兜底即可:dockview(MIT)/ rc-dock(Apache)、three.js(MIT)、Mermaid(MIT)——均无 kill-switch、可离线、可 fork。

**自主可控修订推荐(P1 起步):**

> **AntV X6(2D 图,国产 MIT)+ dockview 或 rc-dock(停靠)+ three.js(3D)+ Mermaid(文本)**,全部 vendor 进私有仓、锁版本、可离线构建。
> React Flow(MIT)留作"开源可控但非国产"的国际备选;**GoJS/JointJS+/tldraw 全部不纳入**。

**配套自主可控措施(写进卡的红线):** 选定依赖**镜像/vendor 进私有仓库**、锁定版本与校验和、**离线可构建**(不依赖外网 CDN/license 服务)、关键件保留 fork 分支。
