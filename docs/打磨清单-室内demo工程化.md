# 室内 demo 工程化打磨清单(对齐原型 + 一进来就有数据)

> 目标:把室内工作台从"功能通"打磨到"可对外演示、贴近 Claude Design 原型"。按 demo 冲击力排序,逐卡消。
> 像素基准:`docs/design/M-Next 工作台.dc.html` / `户型工作台.dc.html` / `首页.dc.html` / `图元风格概念.dc.html`。

## P0 — 一进来就有数据(消"栏目白、点了才出")
1. **模型树默认有根**:进工作台自动以户型(floorplan)为根加载树(室内:floorplan contains room);缺根时回退列出对象,不再空白。
2. **校验面板默认出态**:进入即显示当前各对象规则灯汇总(红/黄/绿计数 + 列表),而非"点击运行校验";"重新校验"按钮保留。
3. **标签页预热(可选)**:表格/矩阵/文档 tab 首次激活前给骨架/占位,不是纯白;或进入时后台预取,点开即有。
4. **失焦自动保存** ✅(已做):属性区改字段失焦即存。

## P1 — 视觉贴齐原型
5. **外壳细节**:顶栏菜单(文件/编辑/视图/模型/校验)、工具条(选择/连线/自动布局)、视图入口按 `工作台.dc.html` 补齐排布与图标,不只是几个裸按钮。
6. **三栏比例与留白**:左树/中画布/右属性 的宽度、分隔、留白贴 dc.html;面板标题栏样式统一。
7. **空态/加载态**:每个面板的空态有插画/提示文案 + 加载骨架,不是纯白(对齐"模型优先、安静"的基调)。
8. **平面图真实布局**(已出卡 T-V33-FLOORPLAN-LAYOUT):房间按真实坐标摆成公寓样。

## P2 — 交互细节
9. **错误用 toast/状态条**,不是底栏数字 + 控制台红字;保存成功有轻提示。
10. **选中/悬停**:画布与树/属性联动高亮一致;hover 态、选中态贴 dc.html。
11. **新建项目向导接通**:命名→选室内→进工作台真正创建并打开新工作空间。
12. **维度切换**做成分段按钮组(原型样),切换有过渡。

## P3 — 工程化/稳健(往可商用靠,demo 非必需)
13. dev 后端独立化(不被前端带死)/ 一键起停加固。
14. 投影高频写入追平(读模型积压治理)、读写一致性可视化。
15. 真实登录/SSO(替换 demo-actor 占位)。
16. 一份《室内 demo 演示脚本》:暗次卧采光不足(红)→ 加窗 → 达标(绿)的可复述流程。

## 执行顺序(建议)
P0(1→2→3)先消"白栏目" → P1(8 平面图、5/6/7 外壳与空态)贴原型 → P2 交互 → P3 工程化。
每项一卡:纯前端为主、零后端/契约优先;命中后端/迁移停下回报。
