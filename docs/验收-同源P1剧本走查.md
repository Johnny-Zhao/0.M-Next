# 验收-同源P1剧本走查

> 范围:T-US-001~006 同源 P1 剧本。每步包含操作、预期、对应屏。

1. 打开 `/us/home`。
   预期:首页显示对象、引用、待确认、校验等终态数字。
   对应屏:首页。

2. 进入产品规格库表格,将门锁 S3 售价改为另一个值,再撤销。
   预期:字段写入走数据轨,撤销后引用恢复同步状态。
   对应屏:表格视图。

3. 打开分屏表达,点选陈默相关记录。
   预期:选中态与右侧/日志联动,琥珀提示能回落。
   对应屏:分屏联动。

4. 打开 S3 规格书,使用 `@引用字段`,再对悬空引用执行重绑。
   预期:RefChip 插入成功,悬空 chip 重绑后变为正常引用。
   对应屏:文档视图。

5. 进入 `/us/import`,点击“去确认”并完成低置信项确认。
   预期:6a 置信门控生效,确认后写入,待确认横幅消失。
   对应屏:AI 导入。

6. 打开看板 AI 对话,输入“把续航改到 14,并加活跃渠道数”。
   预期:行动卡生成,王芸身份可写入,BI 卡出现;撤销全部后恢复。
   对应屏:AI 对话 + BI。

7. 切换为陈默,在表格编辑产品规格库售价。
   预期:越权写入转为待审批,数据不直接落库。
   对应屏:表格视图 + 权限模型。

8. 进入 `/us/settings/access`,王芸批准陈默的待审批。
   预期:值按陈默 actor 落库,王芸审批记录写入,引用 justSynced;拒绝分支零写入。
   对应屏:权限模型 8b。

9. 进入 `/us/source/validate`,点击 XSRC-001“立即同步”。
   预期:渠道缓存价变为 1199,规则转通过,错误计数减少。
   对应屏:校验中心 9c。

10. 在 REF-002 点击“定位到文档”,完成悬空引用重绑。
    预期:跳转到文档并闪烁目标 chip,重绑后 REF-002 通过。
    对应屏:校验中心 + 文档视图。

11. 对 TPL-003 点击“换用 ATX 型号”。
    预期:模板警告消失;两条错误修复后分享按钮从禁用变为可用。
    对应屏:校验中心。

12. 对某校验错误执行“设为例外”。
    预期:卡片置灰,不再阻断分享,ReviewRecord 与活动流留痕。
    对应屏:校验中心。

13. 切换周然身份观察数据。
    预期:只读/无权限能力清单正确,写操作不可直接落库。
    对应屏:权限模型。

14. 从身份菜单点击“重置演示数据”。
    预期:身份、聊天、审批、校验忽略项和数据全部回到初始状态;重复点击结果一致。
    对应屏:全局 DEV 工具。
