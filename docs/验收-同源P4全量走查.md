# 验收-同源 P4 全量走查

范围:015 读路径双模式、016 写路径桥接、017a 校验权威叠加、017b AI 变更集旁路、017c 审批与 G2 投影、018 输出/快照导出闭环。

## 1. 双模式装载与回退

1. 启动:`corepack pnpm dev:up`。
2. 打开 `/us?backend=1&ws=<workspaceId>`。
3. 预期:页面显示 backend 装载报告;对象/关系来自内核读模型。
4. 移除 `?backend=1` 或选择回退 Mock。
5. 预期:Mock 剧本、模板配置单本地文档与原演示路径保持不变。

## 2. 写路径与冲突回滚

1. backend 模式下以王芸修改一个产品规格字段。
2. 预期:写桥以当前 session 成员作为 `X-Actor-Id`,经内核命令落库。
3. 制造版本冲突后再保存。
4. 预期:前端显示冲突/失败提示,本地乐观状态回滚,不污染 Mock 数据。

## 3. 校验权威叠加

1. 进入 9c 校验中心,点击「立即运行」。
2. 预期:本地规则仍显示;内核 checkResults 叠加展示。
3. 预期:分享/导出阻断同时参考本地未忽略 error 与内核阻断项。

## 4. AI 变更集旁路

1. 进入 6a AI 导入。
2. 预期:scripted AI 导入流程仍可演示;backend 模式额外显示「内核 AI 变更集(权威)」。
3. 点击同步,预期读取 `views/ai-changes?status=PROPOSED`。
4. 点击确认所列项,预期发送 `ConfirmAiChange` 且 payload 带 itemIds。
5. 点击拒绝,预期发送 `RejectAiChange`。

## 5. 审批与 G2 投影

1. 切换陈默,尝试修改产品规格库字段。
2. 预期:前端闸转为待审批,不直发内核。
3. 切换王芸,批准并写入。
4. 预期:016 写桥以王芸作为 actor 落内核;陈默只作为本地请求归属。
5. 进入权限页,预期空间角色投影为王芸 ADMIN、李晓 AUTHOR、陈默 AUTHOR、周然 VIEWER。

## 6. 输出/快照导出闭环

1. 确保模板槽位可生成且校验无未忽略 error。
2. backend 模式进入模板画布,点击「导出 DOCX」或 PDF/CSV。
3. 预期调用顺序为 `captureSnapshot` → `createOutput` → `getOutput` → 浏览器下载。
4. 制造校验 error 后重试导出。
5. 预期:按钮禁用或拒绝导出,不发内核输出请求。
6. 回到 Mock 模式点击「生成配置单 DOC」。
7. 预期:仍打开本地 `template-config-doc` 文档,不走内核输出源。
