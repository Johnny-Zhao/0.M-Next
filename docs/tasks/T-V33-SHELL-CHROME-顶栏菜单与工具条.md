# T-V33-SHELL-CHROME — 工作台顶栏菜单 + 工具条(贴 工作台.dc.html)

蓝本:`docs/design/M-Next 工作台.dc.html`。
**packages/web 域,纯前端,零后端/契约。** 前置:main(已含 SHELL-FLUENT / PANELS-AUTOLOAD)。
定位:现工作台顶栏只是几个裸按钮(返回项目/对象类型/关系类型/根对象/刷新/生成文档),与原型的"菜单栏 + 工具条"差距大。本卡按 dc.html 补齐**菜单栏**与**工具条**,让外壳像专业建模工具。

## 现状
- `workbench.tsx`/`app.tsx` 顶栏:M-Next + 返回项目 + 工作空间下拉 + 对象类型/关系类型/根对象输入 + 刷新 + 生成文档 + 亮暗切换。功能在,但排布散、无菜单/工具条层次。

## 范围(纯前端,贴 dc.html)
- **A. 菜单栏**(顶部第一行,按 `工作台.dc.html`):**文件 / 编辑 / 视图 / 模型 / 校验** 等菜单(下拉)。菜单项**复用已有动作**(如 视图→打开 图/表/矩阵/文档/平面图 面板;校验→运行校验;文件→生成文档/导出;模型→刷新/新建对象入口占位)。没有真实动作的项给禁用态或"待接入"标注,不杜撰功能。
- **B. 工具条**(第二行/菜单下):**选择 / 连线 / 自动布局** 等图操作按钮(图标 + tooltip),作用于画布;**视图入口**按钮组(图/表/矩阵/文档/平面图)切换面板;**维度切换**分段按钮组(全部/能量/热/质量/光/风);右侧 **重新校验**、**生成文档/导出**、**亮暗切换**。
- **C. 参数区收纳**:对象类型/关系类型/根对象这些"开发态参数"收进"高级/视图设置"弹出或次级区,不占主工具条(默认值已能直接出数据,普通用户无需碰)。
- **D. 全 `--mn-*` 令牌、Fluent 浅色、亮暗双主题**;图标用内联 SVG,不引图标库。
