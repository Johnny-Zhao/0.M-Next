# 任务卡 T-US-022 — P5 批3:血缘可视化(字段派生血缘接内核 lineage)

- 状态:**可下发**(内核 lineage 端点已就绪;依赖 P4 015–019 + 020/021 已合并)
- 性质:**P5 批3 feature 卡——读-only 可视化,含新血缘 drawer**。把字段派生血缘接内核 `lineage`,兑现同源「一份数据、字段引用 live 同步」的核心叙事
- PR 要求:`Spec-Ref: packages/views/src/api/view-client.ts(lineage / LineageView / LineageNode)、packages/web/src/unisource/state/selection-store.ts(选中字段锚点)、packages/web/src/unisource/doc/ref-chip.tsx(FieldRef 引用系统)、docs/tasks/T-US-020(drawer 与模式注入口径)、docs/tasks/T-US-017a(fire-and-forget)` + 自检输出段
- 序列位置:P5 批3;在真实导入(021)之后,血缘对真实数据更有意义

## 背景与关键决策(必读)

**现状(务必先读代码):** unisource **无血缘 UI**;字段引用现有 `FieldRef`/`doc/ref-chip.tsx`(文档→源字段的引用)。内核 lineage **已就绪、前端零消费**:`view-client.lineage(ws, objectId, fieldCode)→LineageView{objectId, fieldCode, upstream: LineageNode[], downstream: LineageNode[], algorithm:{kind:"stored"|"derived"|"rule", ref}, partial, truncated}`;`LineageNode{kind:"field"|"derived"|"rule"|"recommendation", objectId, objectType, fieldCode, ref, source, updatedAt, depth}`(带 `depth` 可做层级布局)。gateway 无 lineage 方法。

**决策 1 —— 血缘 drawer(本卡 UI 主体),锚定选中字段。**
新增血缘 drawer(`?drawer=lineage`,**镜像 020 的 annotation drawer** 挂载/开关),锚定**当前选中字段**(`selectionStore` / grid 单元格选中 / RefChip)。上游(此字段派生自谁)← 字段 → 下游(谁依赖此字段),按 `depth` 分层;`algorithm` 徽标标 stored/derived/rule。**⚠️ drawer 挂载点镜像 annotation drawer 是本卡定的,审查确认。**

**决策 2 —— 模式分叉(仿 017a/020「保留本地 + 内核」)。**
**backend** → `gateway.lineage(objectId, fieldCode)` → 内核 `LineageView`(完整 upstream/downstream/algorithm);**Mock** → **本地下游**(从 `workspace.fieldRefs` 取引用此字段的 expr/doc 作 downstream),无 upstream(派生血缘属内核),algorithm 标 "本地引用"。两模式锚同一字段,演示对齐「live 同步引用」。

**决策 3 —— 读-only。** lineage 无写命令;`lineage-store` 只有异步 `refresh(objectId, fieldCode)`(**fire-and-forget**:setActor→lineage→存片→(失败 Toast、不抛、busy 复位));无 rollback、无 onReload。

**决策 4 —— actor。** refresh 前 `setActor(sessionStore.currentMemberId)`(lineage 读若需 X-Actor-Id 则携带;不需要也无害)。

**范围裁剪(写清理由):**
- **不做写 / 编辑血缘**(读-only)。
- **不做全局血缘图**(仅锚定单字段的 upstream/downstream;跨字段大图另立)。
- **不改 FieldRef/RefChip 引用系统本身**(仅读 `fieldRefs` 作 Mock 下游)。
- **不改 016–021 既有面**。

## 行为要求(逐条可测)

1. **选字段刷新(backend):** 选中字段 + 开 drawer → `refresh(objectId, fieldCode)`→内核 `LineageView`→`kernelLineage` 片;按 `depth` 分层渲染上游/下游 + `algorithm` 徽标。
2. **Mock 本地下游:** Mock 模式 drawer 从 `workspace.fieldRefs` 取引用此字段者作下游;无内核调用。
3. **read-only:** 无写命令、无 onReload、无 rollback。
4. **actor:** refresh 携当前 `sessionStore.currentMemberId`(测试断言,如端点需要)。
5. **fire-and-forget:** 失败→Toast、`busy` 复位、不抛。
6. **partial/truncated:** `LineageView.partial`/`truncated` 为真时 drawer 提示(数据不完整/已截断)。
7. **Mock/演示零回归:** grid/doc/RefChip、剧本不变;drawer 未开时零影响。
