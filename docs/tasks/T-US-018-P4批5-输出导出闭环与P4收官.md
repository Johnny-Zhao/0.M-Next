## 背景与关键决策(必读)

**输出现状(务必先读代码):**
- 「生成配置单」在 `template/template-canvas.tsx`(185–198「生成配置单 DOC」按钮)→ `navigate` 到 `template/template-config-doc.tsx` **本地 doc 渲染**;按钮受 `availability.enabled` 门控(009 的「生成配置单阻断管线」——有校验错则禁)。
- gateway **无** snapshot/output 方法;ViewClient **有**:`captureSnapshot(ws, actor, scopeObjectType?, treeScope?)→SnapshotMeta`(POST /snapshots)、`listSnapshots`/`getSnapshot`、`createOutput(ws, actor, {snapshotId, format, templateId?, …})→OutputMeta`(POST /outputs)、`getOutput(ws, outputId)→OutputDetail{meta, artifact}`、`listOutputs`。`OutputFormat = markdown|docx|pdf|html|csv|xlsx`。
- seed 有 `outputSnapshots`;当前无通用「导出成果」UI,导出即「生成配置单」这一处。

**决策 1 —— A 导出闭环接内核(用户已拍板;仿 017a/b「保留本地 + 内核叠加」)。**
backend 模式的「生成配置单/导出」走内核三步闭环:`captureSnapshot(scopeObjectType)` → `createOutput({snapshotId, format})` → `getOutput(outputId)` 取 `artifact` → **浏览器下载**;**本地 `template-config-doc` 渲染在 Mock/演示模式原样保留**(招牌流不变)。校验门控(`availability.enabled`)沿用——有未忽略 error 则禁止导出。

**决策 2 —— 输出源 mode-aware + 异步 fire-and-forget(对齐 017a/b)。**
新增 `state/outputs-store.ts`:持 `KernelOutputSource`(gateway 子集:`setActor`+`captureSnapshot`+`createOutput`+`getOutput`),经 `setKernelSource(src|null)` 由 boot 注入(kernel 注入、Mock/回退 null);`busy`/`lastOutput` 片;异步 `exportToKernel(format, scope, actor)`:`setActor`→capture→create→get→**download blob**→Toast「已导出 {format}」;**失败只 Toast,绝不抛错**,`busy` 复位。

**决策 3 —— G5 槽位关系化彻底延后(记缺口)。**
`slot_binding` 在 **views 客户端、契约、后端全都没有**(比 ChangeState 更彻底——ChangeState 后端有、只是 client 没暴露)。关系化需一整套**后端 + 契约 + views 新特性**,超出 P4 范围。`bindSlot`/`unbindSlot` **维持前端投影**(现状不动),文档记 G5 缺口 + 后续立项建议。

**决策 4 —— actor 随角色 + 下载实现。**
导出前 `setActor(sessionStore.currentMemberId)`(复用 setActor)。下载:`getOutput().artifact` → 文本类(markdown/csv/html)直接 `Blob([text])`;二进制类(docx/pdf/xlsx)按内核约定(base64)`atob`→`Uint8Array`→`Blob` → `a[download]`(实现点,审查核编码)。

**决策 5 —— 格式范围。** 先接 **docx + pdf + csv + markdown**(UI 出格式选择或「生成配置单」默认 docx + 一个「导出为…」小菜单);xlsx/html 可选。

**范围裁剪(写清理由):**
- **不做 G5/slot_binding 关系化**(决策 3,后端无支撑)。
- **不改本地 `template-config-doc` 渲染与校验门控行为**(演示招牌,Mock 保留)。
- **不做输出的评审/校验状态回写**(`OutputMeta.reviewStatus/checkStatus` 只读展示,不驱动写);snapshot diff/compare 面(A/B)不在本卡。
