## 目标

落地 **snapshotId 不可变快照**:捕获某时点读模型 DataSet 为内容寻址(SHA-256)的不可变行,提供捕获/检索/列表端点,并把 **diff / exchange preview 的 A 侧**接通 `snapshot:{id}`(AG-208 落地第一步)。**快照为派生输出制品:只读 rm_* 捕获、只写 snapshot 表、不可变、不碰主数据、不发内核命令、无新依赖。**

## 涉及文件(封闭清单)

- **新增** `packages/server/.../SnapshotRepository.java`:`capture(workspace, scopeObjectType?, actor)` = 读 `ReadModelRepository.dataSet(...)` → 规范化 + SHA-256 → 插不可变行;`get(workspace, snapshotId)`;`list(workspace, page, size≤50)`。**只读 rm_*,写仅 snapshot 表,无 update/delete。**

- 测试:`SnapshotIntegrationTest`(Testcontainers)。**禁止新增依赖(AG-502)。**

## 行为要求(逐条可测)

1. **捕获**:`POST /snapshots` 读当前读模型 DataSet(可选 scopeObjectType 过滤)→ 规范化(确定性排序)→ SHA-256 → 写不可变行;返回 `{snapshotId, createdAt, dataVersion, contentHash}`。`created_by` 取认证上下文(AG-321)。
2. **不可变**:无更新/删除端点;捕获后 `payload` 字节不变;`GET /snapshots/{id}` 幂等返回同内容。
3. **内容寻址**:相同 DataSet 捕获两次 → 相同 contentHash;改一个字段值后捕获 → 不同 snapshotId + 不同 hash,且旧快照 payload 不受影响。
4. **diff A 侧(AG-208 第一步)**:`POST /diff`(及 exchange preview)`base=snapshot:{id}` → 以快照 DataSet 为 A 侧产出结构化 diff;`base=current` 行为不变。
5. **隔离**:捕获只读 rm_object/rm_relation,**不读主数据全表、不写主数据、不发内核命令、不入 Outbox**(架构断言:SnapshotRepository 无 data_* 访问、无内核命令调用)。workspace 强制过滤(AG-503)。
6. **有界**:列表分页 size≤50。

## 测试要求(jacoco ≥0.80;AG-504 禁 sleep)

必含:捕获→返回 id+hash;`GET` 幂等同内容;改字段后再捕获→新 id/新 hash/旧 payload 不变;相同内容→相同 hash;`diff base=snapshot:{id}` 用快照作 A 侧、`base=current` 不变;workspace 隔离;**架构断言**:SnapshotRepository 不写主数据、不发命令、不读 data_*(源码/SQL 断言)。
