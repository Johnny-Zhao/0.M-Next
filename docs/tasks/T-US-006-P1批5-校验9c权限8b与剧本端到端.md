**决策 2:审批语义。** 「批准并写入」= `confirmAll(changeSetId)`(写入 actor 保持发起人,「谁改的数」可追溯)+ 写 1 条 `ReviewRecord { action:'approve', actor:审批人 }` + 活动流「王芸 批准了陈默的修改…」;「拒绝」= `reject` + ReviewRecord(action:'reject')。**ReviewRecord 首次落地**:workspace-store 增 `addReviewRecord(record)` 与状态载体(`reviewRecords`),9c 的「忽略本次(记录到审计)」同样写 ReviewRecord(action:'accept',note='忽略校验项 XSRC-001')。
**决策 3:分享阻断。** 顶栏 ShareButton 接校验状态:errors>0 → 禁用 + tooltip「存在校验错误,修复后可分享」(交接规格 §06);修复两条错误后解锁。WorkspaceLayout/FullLayout 的 chrome 增可选 `shareDisabledReason`,页面从 ValidationStore 派生传入。
