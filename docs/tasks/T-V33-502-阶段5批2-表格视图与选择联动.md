## 行为要求(逐条可测)

1. **类型驱动列(W-2.1)**:列来自 `GET /views/object-types`(字段 code/name/dataType),非硬编码;行来自 `GET /views/objects?objectType=&page=&pageSize=`(pageSize≤200,AG-202)。
2. **单元格编辑(W-2.2/2.3)**:双击进入编辑,提交 `UpdateFields`(payload 带该字段 `expectedFieldVersion`,契约§5.4);成功→版本+1、回显;`KERNEL-409`→打开 ConflictDialog(§4);其它错误→单元格标记 + 状态栏错误计数,文案取 error-codes 的 title(不透出原码,AG-312/W-5.1)。
3. **终态只读(W-2.4)**:status ∈ {CONFIRMED/VOID/DELETED/FILED…} 的行编辑入口禁用。
4. **SelectionRef 联动(W-3.x,AG-209)**:行点击→object 级选择→详情面板 100ms 内刷新;详情面板字段点击→field 级选择→表格对应单元格描边;**选择是纯前端态:不发命令、不写库、不发全工作空间查询、切换工作空间即清空、不落 storage(仅 `ui.` 前缀偏好)**。
5. **同步状态(W-1.2)**:轮询 `/views/sync-status`,绿=追平/黄=同步中(显示落后数)/红=异常;最终一致延迟必须可见。
6. **隔离(AG-101/102)**:views/web 只经 view-client/command-client 调 `/views/*` 与 `/commands`;不 import kernel/engines/server;不把对象/字段/关系落 localStorage/IndexedDB。
