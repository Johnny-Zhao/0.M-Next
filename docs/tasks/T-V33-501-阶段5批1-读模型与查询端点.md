## 行为要求(逐条可测)

1. **投影幂等(AG-210)**:`apply()` 先查 `rm_consumed_event(readmodel, eventId)`,已存在则跳过;成功投影后登记。重复投递同 eventId 只生效一次。
2. **事件映射**:ObjectCreated→insert rm_object;FieldChanged→更新 fields+version;StateChanged→status;RelationCreated→insert rm_relation;RelationUnlinked/Archived/SoftDeleted→status 终态;RelationUpdated→端点/字段;BatchCommitted 不二次处理(其子事件各自投递)。
3. **顺序/乱序**:按聚合 sequence 应用;若 rm 行现 version ≥ 事件 version 则跳过(防旧序覆盖)。
4. **查询端点(AG-202/203/503)**:全部强制 workspace 范围;objects 必带 objectType + 分页(pageSize≤200,缺省 50);relations 必带 relationType+direction,depth≤5,命中 rm_relation 索引;tree 的 relationType 须 hierarchical;object-types 返回类型+字段定义(dataType/constraints)供列定义;sync-status 返回待投影 PENDING 事件数与是否追平。
5. **隔离**:投影只写 rm_*,**不写 data_object/data_field_value/data_relation、不发任何命令**;查询只读 rm_*,**不回查主数据表**(架构断言 + SQL 扫描)。
6. **RabbitMQ 封装(AG-506)**:RabbitMQ 客户端只在 `ReadModelRabbitListener`;`ReadModelProjection` 可脱离 RabbitMQ 直接单测。
