## 背景与关键决策(必读)

P1 + 视觉打磨已合入。P2 画布批开跑,本卡立起画布底座 —— 7a 是设计稿信息密度最高的屏:多选编辑、视图布局与数据的边界(移除≠删除)、双轨版本流,全在这一屏。

**决策 1:React Flow 直接复用。** `@xyflow/react@12.11.0` 已是 web 包依赖(现有工作台在用),unisource import 不违反零新依赖;`@xyflow/react/dist/style.css` 在 unisource/app.tsx 引入(仅同源壳加载,顺序在 us-tokens 之前),RF 默认样式用 `.us-canvas` 作用域覆盖为 token 化。对齐/分布数学**从 `packages/web/src/workbench/align.ts` 复制适配**到 `canvas/align.ts`(注明来源;不 import 旧工作台模块,避免耦合;函数签名按本卡节点形状调整,连同测试一起搬)。
**决策 2:画布布局 = ViewDef.config,写入走 view 轨且可恢复。** workspace-store 增 `updateViewConfig(viewId, patch, meta)`:合并 config、产生 ChangeEvent(track='view')+ 表达轨活动流;**模型小扩**:`ChangeEvent` 增可选 `inverseView?: { viewId, patch }`(前值补丁),`undo(eventId)` 分派:field 事件走既有 inverse,view 事件重放 inverseView(同样是一次新写入)。这让 7a 版本面板的「恢复」对双轨都成立。若实现超预算,允许降级为「view 轨仅展示不可恢复」并在 PR 声明(弹性条款)。
**决策 3:删除闭环首次落地(DeleteConfirmModal,缺稿 08-① 按交接规格文字自实现)。** workspace-store 增 `deleteObject(objectId, actor)`:移除对象、其 fieldRefs 全部转 dangling、data 轨事件(inverse:null,**不可撤销**)+ 活动流;校验自动重跑(REF-002 复活/加重)→ 分享重新阻断 —— 「删除的代价全链路可见」是本卡最强的演示点。弹窗必含:受影响表达清单(由 fieldRefs+画布节点派生,含各自引用数)、**输入对象名称确认**、不可撤销声明、危险按钮;`resetDemo` 可整体复原。
**决策 4:「从数据源添加」用点击弹层,不做拖拽。** 设计的 DataTreeRow 拖出/DragGhost 留 P2 尾卡;本卡工具栏「从数据源添加」→ 弹层列该库对象(已在画布的置灰)→ 点击添加节点(updateViewConfig)。

## 行为要求(逐条可测)

1. 画布渲染 seed 的 4 节点 3 连线,坐标/标签与 config 一致;拖动节点 → config 更新 + view 轨事件 + 活动流;刷新页面布局保持(store 内存态,同会话)。
2. 多选:框选/Shift 点选 ≥2 → 对齐工具条浮出 + 选中态(2px+glow+手柄);selection-store 断言零写入不回归。
3. 对齐/等大小:三节点左对齐 → x 归一、一次 view 轨事件(批量);「恢复」该条 → 坐标回前值(inverseView 重放,version 前进)。
4. 移除 vs 删除:「移除出视图」→ 节点消失、对象仍在(表格页可见)、view 轨事件;「删除数据源记录」→ 弹窗动态影响面 → 输入名称 → 删除 → 对象从全库消失、其引用全 dangling、REF-002 报错数上升、分享按钮转禁用、活动流 data 轨记录;resetDemo 复原。
5. 定位到显示处:子菜单列出该对象真实引用点(计数正确);点「表格」→ source 页对应行闪烁;点「文档」→ doc 页 chip 闪烁(locate 机制)。
6. 连线:连线模式点 S3 → M1(或任意两节点)→ 新 DataRelation(data 轨)+ 画布新边 + Toast「已写回互联关系」;版本面板出现该条(仅数据筛选可见)。
7. 样式面板:改填充/圆角/显隐 → 节点即时反映 + view 轨事件;多选不同字号显「混合」;协议标签开关 OFF → 边标签隐藏。
8. 权限:周然(exp-portal 无编辑权,按 seed 权限矩阵定;若矩阵无此表达列,给 seed 补 `exp-portal` 资源列:王芸 edit/李晓 edit/陈默 edit/周然 readonly)→ 画布可平移查看、工具栏与样式面板禁用、右键仅「定位到显示处」。
9. 运行仿真按钮 → `?run=1` 骨架页(标注 010);返回画布状态不丢。
