## 行为要求(逐条可测)

1. **AG-208**:`POST /outputs` 入参**只接 snapshotId**;无快照 id / 传 workspaceId 直渲 → 拒(400)。
2. **渲染**:载快照 DataSet → `RenderRegistry.require(format)` 渲染为字节;format ∈ {html,markdown,csv};未知 format → 400/404。
3. **输出快照**:写一条 output_snapshot,记 data_snapshot_id、format、data_version、review/check_status(MVP:从快照元数据带或置默认)、created_by(认证上下文 AG-321)、content_hash=SHA-256(产物)、artifact。
4. **不可变**:无更新/删除;`GET /outputs/{id}` 幂等返回同字节。
5. **隔离/纯**:`RenderAdapter` 及三实现在 engines/output,**无 Spring/JDBC/SQL/命令**(架构断言);输出只读消费快照、**不写主数据、不发命令**(AG-110 不涉);workspace 强制过滤(AG-503)。
6. **可插**:ServiceLoader 能发现 classpath 上的 RenderAdapter;测试放一个 `TestPlainRenderAdapter` 证外部可插(不进生产)。
