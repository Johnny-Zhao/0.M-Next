## 行为要求(逐条可测)

1. **连**:空格提交 → 以 `(relationType, rowObjectId→colObjectId)` 调 `createRelation`;成功后该格显示关系标记。
2. **断**:命中格"断开" → 以 `(relationId, expectedVersion)` 调 `unlink`;成功后该格清空。
3. **冲突**:`KERNEL-409`(版本漂移/重复关系等)→ 既有冲突弹层,不静默吞。
4. **终态/只读**:终态对象所在行/列单元格不可编辑;未注入 `commandClient` → 全只读(603 行为)。
5. **隔离**:写仅经 `CommandClient`(AG-110);选择联动仍零写、零全图查询(AG-209);视图不 import 内核/引擎(AG-101)。
