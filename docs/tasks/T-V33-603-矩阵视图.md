## 行为要求(逐条可测)

1. **端点**:`/views/matrix` 强制 workspace 过滤(AG-503);`rowSize`/`colSize` >50 → 截到 50;返回分页行列对象 + 落在本页行×列内的关系单元格 + rowTotal/colTotal。
2. **只读隔离**:查询只读 rm_object/rm_relation,**不读主数据全表、不写任何表**(架构断言:matrix 查询无 data_* 访问、无 insert/update/delete)。
3. **渲染**:`MatrixView` 表头=列对象、行头=行对象、单元格命中关系显示标记 + status;空单元格留空。row=col 同类型方阵正常渲染。
4. **关系级联动**:点单元格 → `selection.select({entityType:'relation', entityId:relationId})`;反向 `subscribe` 命中关系 → 单元格描边 + 行/列头弱高亮。**零写(AG-209)。**
5. **对象级联动**:点行/列头 → `select({object, objectId})`;反向命中对象 → 整行/整列弱高亮。
6. **有界**:行列各 ≤50/页,翻页经端点参数;不一次拉全集(AG-202)。切工作空间清空。
