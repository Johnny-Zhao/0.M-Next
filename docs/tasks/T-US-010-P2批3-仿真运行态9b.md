## 背景与关键决策(必读)

008/009 已合入:编辑画布与模板画布都立住了。本卡做 9b —— 同一张 exp-portal 画布的**运行态**:事件沿连线传播,「连线流动 = 事件传播;延迟取自节点『协议』字段」。9b 的核心叙事是**数据一改,回放结果随之变化**(侧栏底注原文),所以时序必须从数据派生,不能写死。

**决策 1:时序 = 纯函数派生,延迟查表读 relation.protocol。** `SimScenario` 扩(现占位 `sim-door-open` 替换):`SimEvent { nodeObjectId, viaRelationId?: string, label, kind: 'source'|'relay'|'action', check?: boolean }`(**不存绝对时刻**);`sim/sim-timing.ts` 纯函数 `deriveSimTimeline(scenario, workspace, network)`:source 事件 t=0,后续事件时刻 = 前驱时刻 + `protocolDelay(relation.protocol)`(查表:`Wi-Fi`/`BLE`→0.4s、`推送`→0.6s、`联动录像`→2.8s、未知→0.5s,注释标注「示意基准」;弱网 = 全部 ×1.5 且重试计数 +N)。seed 终态复现设计稿时刻:S3 00:00.0 指纹开锁(事件源)→ G2 00:00.4 收到事件(经 rel S3—G2)→ D2 Pro 00:01.0 推送弹窗✓(经 rel D2—G2)→ E1 00:03.2 联动录像(经 rel E1—G2),duration 10s。**这样在画布改 S3—G2 协议(`updateRelationField` 既有)→ 再运行,后续全部时刻与端到端指标随之变 —— 本卡最强演示点。**
**决策 2:回放引擎 = 组件局部 UI 态,不进全局 store。** 运行态零业务写入(不产生 ChangeEvent/不碰 workspace,断言见测试);`sim/sim-playback.ts` 纯函数:`advancePlayhead(playhead, dt, speed, duration, loop)`(循环回卷/非循环钉在末尾)、`deriveNodePhase(timeline, playhead)` → 每节点 `idle|source|running|done`(source 恒显「事件源」徽标;running=琥珀边+PulseRing;done=✓+时刻)与每边 `flowing|idle`(事件已经过该边=流动);组件内 `useState + 100ms interval × speed` 驱动,**进度、事件时间线当前行、画布节点状态三处同步全部由同一 playhead 派生**(交接规格 §06 原文)。
**决策 3:画布复用 008,新增可选 sim 渲染分支。** 允许修改 `canvas/node-card.tsx` 与 `canvas/edge-labeled.tsx`,**仅限新增可选 props/data-attr**(如 `data-sim-phase`、时刻角标、FlowEdge 流动类),默认(无 sim 数据)渲染路径与既有测试零回归;`sim/sim-view.tsx` 用 RF 装配(读同一 ViewDef.config 坐标,节点不可拖、无右键、无对齐条、无 inspector 三面板)。运行态对所有身份可用(纯读,周然也能运行)。
**决策 4:右侧面板 = 仿真参数(SIMULATE),替换 Inspector。** 场景行(单场景「访客到访 · 指纹开锁」,下拉样式禁用态);网络段控(正常/弱网,§02 SegmentedControl,切换即重派生时序并重置 playhead);「事件时间线 · TIMELINE」(每行 Mono 时刻 + 摘要,当前行琥珀高亮,末行 `00:10.0 回放结束 · 循环`);「指标 · METRICS」瓦片(端到端延迟 = 最后 action 时刻 **live**、日耗电(估)+0.8% 静态示意、事件数 N、弱网重试(正常 0/弱网 >0),数值全 Mono);底注「仿真结果可存为快照,随规格书一起发给客户。」(纯文案,不做快照)。

1. 入口/出口:canvas 右下 RunButton ▶ → `run=1` 运行态;「停止」→ 回 canvas,编辑态(选择/布局)不丢;直接刷新带 `run=1` 的 URL 也能进运行态。

6. 指标 live:端到端延迟 = 最后 action 事件时刻;事件数正确;数值全 Mono。
7. 零业务写入:运行/暂停/倍速/弱网/停止全程 changeEvents 与 workspace 版本不变(断言);选择联动零写入不回归(AG-209)。
