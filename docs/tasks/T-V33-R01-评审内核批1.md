## 行为要求(逐条可测)

1. **CreateAnnotation**:`targetType ∈ {object,field,relation}`;目标必须存在(经 kernel/api 只读校验)→ 否则 `REVIEW-404-TARGET-NOT-FOUND`;`field` 级 `fieldCode` 必填且该字段定义存在 → 否则 `REVIEW-422-FIELD-CODE-REQUIRED`;`object/relation` 级若传 fieldCode → `REVIEW-400-SCHEMA-INVALID`;`anchoredDataVersion` 由客户端传入(其所见版本)并原样固化;`severity ∈ {info,suggest,issue,block}`;`status=open`。
2. **ResolveAnnotation**:仅 `open → resolved`,否则 `REVIEW-409-INVALID-STATE-TRANSITION`;填 `resolved_by/resolved_at`;**断言事务内零主数据写**。
3. **ReopenAnnotation**:`resolved|wontfix → open`,清 resolved_by/resolved_at。
4. **查询**:按 `(workspace,targetType,targetId,fieldCode?)` 返回批注列表,含 `anchoredDataVersion`、`status`、`severity`、`createdBy`;**批1 不计算 stale**(返回锚定版本供前端比对,stale 接通阶段5)。
5. 审计:创建/状态变更填 `created_by/resolved_by`(认证上下文,AG-321);**本批不发评审域事件**(进批2/addendum,留挂点)。
