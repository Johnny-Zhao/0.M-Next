## 目标

把文档视图的字段从"只读 + 跳表格编辑"升级为**就地编辑**:在文档里改字段值 → 经 `UpdateFields` 命令(带 `expectedFieldVersion`)回写(AG-110)→ 投影刷新后只更新受影响的对象节段/字段(承 §D.4"数据引用块只刷新受影响块")→ 字段版本漂移则 `KERNEL-409`,复用 502 既有冲突弹层。**纯前端、零新后端、零新命令/事件/依赖。**

## 涉及文件(封闭清单)

- **修改** `packages/views/src/document/document-view.tsx`:
  - `DocumentViewProps` 新增可选 `commandClient`(类型复用 `../api/command-client` 既有 `CommandClient`)。
  - `DocumentFieldView` 非终态字段渲染为可编辑控件(点击/聚焦进入编辑;dataType 驱动:`text`→多行、`boolean`→开关、`enum`→下拉、其余→输入框);提交 → `commandClient.updateFields(workspaceId, objectId, [{fieldCode, value, expectedFieldVersion}])`(版本取自该对象当前 `version`)。

## 行为要求(逐条可测)

1. **进入编辑**:非终态字段可进入编辑态;终态(archived/soft-deleted)字段保持只读、不可编辑(承 601)。
2. **提交回写**:提交 → `UpdateFields` 命令携 `expectedFieldVersion`=该对象当前 version;**唯一写通道是命令入口(AG-110)**,文档组件不直写任何存储。
3. **成功刷新**:命令成功 → 仅刷新该对象所在节段的字段值与 version(承 §D.4 增量刷新),不整篇重载、不触发全工作空间查询(AG-201/202)。
4. **冲突**:版本漂移 → `KERNEL-409` → 弹出**既有**冲突弹层(与表格同语义),展示当前值/最新值,用户确认后以最新 version 重提或放弃;放弃则恢复原值。
5. **隔离**:编辑只改字段值;**不触碰选择协议**(选择仍纯前端零写,AG-209);不发评审/交换相关命令。
6. **向后兼容**:未注入 `commandClient` → 退回 601 只读 + "在表格中编辑"跳转。
