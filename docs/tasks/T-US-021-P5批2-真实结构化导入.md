## 背景与关键决策(必读)

**现状(务必先读代码):** 6a `import/import-view.tsx` 是**脚本 AI 解析**(报价邮件→本地 changeset,017b 叠加内核 aiChanges)。**结构化导入是另一条路**——内核已就绪、前端零消费:`view-client.exchangePreview(ws, format, payload, base="current")→ExchangeDiffResult`(**dry-run**:解析制品、算与当前的 diff、**不写**)+ `command-client.exchangeApply(ws, format, payload)→ExchangeApplyResult{diff, applied[], unapplied[{item,error}]}`(**写**,需 `X-Actor-Id`)。`ExchangeFormat = "json" | "reqif"`。`ExchangeDiffResult` 富:objects/relations 各 `added[]/removed[]/changed[]` + `summary` 计数。

**决策 1 —— 两步流:预览 → 确认 → 重载。**
① `exchangePreview`(不写)拿 `ExchangeDiffResult`,UI 展 summary(新增/删除/变更计数)+ 逐对象/关系变更;② 用户确认 → `exchangeApply`(写)拿 `ExchangeApplyResult`(applied/unapplied);③ 成功后**触发 backend 重载**(复用 `demo-reset` 的 `configureBackendReload` / 现有 `load`),让导入数据上屏。**重载会重取整个工作区**——exchange 是刻意批量操作,可接受;文档标注会丢弃未落的本地乐观写(正常流程无)。

**决策 2 —— 格式仅 json + reqif(Excel 出局,记 gap)。**
`ExchangeFormat` 只这两种。**Excel/xlsx 不是 exchange 格式**,需转换器(Excel→json 前端解析或后端 Excel 适配),**本卡不做**,记缺口(6a 面板"xlsx·pdf·img"是脚本演示话术,与本卡结构化导入无关)。

**决策 3 —— backend-only + actor 随角色。**
导入面 **backend 门控**;Mock 无 exchange 端点 → 禁用 + 提示"结构化导入需连接内核"。`exchangeApply` 前 `setActor(sessionStore.currentMemberId)`(需 `X-Actor-Id`);预览也带 actor。

**决策 4 —— 新导入面(本卡 UI 主体)。**
新增 `import/structured-import.tsx`,挂在导入页(与脚本 6a 并列、**backend 段**):粘贴/上传 artifact 文本 + 格式选(json/reqif)+「预览」→ diff 摘要卡 +「确认导入」→ 结果(applied N / unapplied M + 逐条错误)。**⚠️ 面板挂载在导入页 backend 段是本卡定的,审查确认。**

**决策 5 —— 模式注入 + fire-and-forget(对齐 017a/b)。**
新增 `state/structured-import-store.ts`:持 `KernelExchangeSource`(gateway 子集:`setActor`+`exchangePreview`+`exchangeApply`),经 `setKernelSource` 由 boot 注入(+ `onReload` 回调 = backend 重载);状态片 `{preview: ExchangeDiff | null, applyResult | null, busy}`;异步 `preview(format, payload)`/`apply(format, payload)`(**fire-and-forget**:setActor→端点→存结果/apply 后 onReload→Toast;失败 Toast、不抛、busy 复位)。

**范围裁剪(写清理由):**
- **不做 Excel/xlsx 导入**(非 exchange 格式,决策 2)。
- **不改脚本 6a 与 017b 内核 aiChanges 叠加**(两条独立路)。
- **不做 exchange 导出**(`exchangeExport` 是反向,另立);不做快照 diff(a/b 双快照 `diff()` 另事)。
- **不改 016–020 既有面**。

## 行为要求(逐条可测)

1. **预览(dry-run 不写):** `preview(format, payload)`→`exchangePreview`→`ExchangeDiff`(summary + objects/relations 变更);不触发写、不重载。
2. **应用(写 + 重载):** `apply(format, payload)`→`exchangeApply`→`ExchangeApplyOutcome`(applied/unapplied)→**onReload**(backend 重载)→Toast「已导入 N,跳过 M」。
3. **backend-only:** 导入面仅 backend 渲染/可用;Mock 禁用 + 提示。
4. **actor:** 预览/应用携当前 `sessionStore.currentMemberId`(测试断言 apply 的 `X-Actor-Id`)。
5. **fire-and-forget:** 失败→Toast、`busy` 复位、不抛。
6. **unapplied 呈现:** apply 结果逐条列未应用项与错误。
7. **Mock/演示零回归:** 脚本 6a、017b 叠加、剧本不变。
