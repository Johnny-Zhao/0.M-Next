## 目标

落地**多维结构化 diff 纯引擎**:给定两个数据集 A、B,产出对象 diff / 属性级 diff / 关系 diff;版本 diff 为其特例。**纯函数、无 I/O、不写主数据、不发命令**(AG-108/201)。这是 702 JSON 交换"解析→diff→回写"的基础。

## 涉及文件(封闭清单)

- `packages/engines/src/main/java/com/mnext/engines/exchange/`:`DataSet`(record:objects[]、relations[],含 objectId/objectTypeCode/fields/status/version、relationId/relationTypeCode/source/target/fields)+ `DiffResult`(对象 added/removed/changed,changed 含属性级 added/removed/changed + statusChanged;关系 added/removed/changed;summary)+ `StructuredDiff`(纯静态 `diff(DataSet a, DataSet b): DiffResult`)。仅依赖 `shared`/JDK。
- server:`DiffController`(`POST /workspaces/{id}/diff`,体含 A、B 或 `{base:'current', other:DataSet}`;`current` 时由读模型拼 A——读 rm_*,只读)+ DTO。
- 测试。**禁止新增依赖(AG-502)。**

## 行为要求(逐条可测)

1. **对象 diff**:B 有 A 无→added;A 有 B 无→removed;两边都有但字段/状态不同→changed。
2. **属性级 diff**:changed 对象内,逐字段给 added(新字段)/removed(去字段)/changed({from,to});statusChanged 给 {from,to}。
3. **关系 diff**:按 relationId 比对 added/removed;端点或 fields 变→changed。
4. **版本 diff(特例)**:A、B 各取同一 objectId 的两个版本→输出该对象的属性级 diff(同引擎,无需特例代码)。
5. **纯净**:`StructuredDiff.diff` 无任何 DB/网络/命令调用;确定性(相同输入相同输出,字段顺序无关)。
6. **diff 端点只读**:`/diff` 不写任何表、不发命令;`base='current'` 仅读 rm_*(AG-202 带 workspace 范围)。
