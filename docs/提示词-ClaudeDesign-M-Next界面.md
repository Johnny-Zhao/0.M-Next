# 提示词 · 给 Claude Design 设计 M-Next 界面

> 用法:把下面"提示词正文"整段复制进 Claude Design;出稿后导出 HTML,发回我(Cowork)转成前端实现卡。一次只让它聚焦这 4 屏,别让它发散去设计全产品。

## 提示词正文(复制以下全部)

你是一名资深 B 端产品设计师。请为一款叫 **M-Next** 的 Web 工程建模工具设计 **4 个高保真界面 + 可点原型**。

**产品一句话**:M-Next 把"画图"变成"在一个活的数据模型上工作"——你画的图背后是结构化数据,**改一个数字,图、属性、规则提示、文档会一起自动更新**。第一个落地领域是**室内设计(户型)**。

**整体风格**:
- 深色科技风为主(深蓝黑底 + 一个冷色强调色),专业、克制、信息密度高;参考 Microsoft Fluent / Office 2026 的质感,不要花哨渐变、不要卡通。
- "模型优先":界面安静,让数据和图是主角;次要功能收进入口,点击再展开(最小常驻 + 渐进式展开)。
- 中文界面。字体清晰,层级分明。

**要设计的 4 屏**:

**① 登录**:居中卡片。Logo "M-Next" + 一句副标题"数据驱动的工程建模平台";账号、密码输入;"进入"主按钮;次要"企业 SSO 登录"。简洁、不要大片留白飘散。

**② 项目列表(首页)**:顶部 "M-Next" + 右上"新建项目"按钮;搜索框(搜项目/模块);下面是**项目卡片网格**(2~3 列)。每张卡片显示:项目名、用到的模块标签(如"室内设计""选材")、我的角色、**规则健康度小圆点**(红=有阻断/黄=有警示/绿=健康)、最近修改时间。给 3 张示例卡片(卫星X总体、技术方案A、样板户型)。

**③ 新建项目(弹窗)**:轻量弹窗。项目名输入;"起步方式"四选一卡片(室内设计、系统工程、技术方案、空项目);"创建并进入"按钮。说明文案:"进项目后能力随用随装"。

**④ 工作台(室内设计场景,最重要,请最用心)**:经典三栏可停靠布局 +顶部工具条。
- **顶部工具条**:左"返回项目";中间一组**维度切换**按钮 [全部] [风] [热] [光];右边一排**视图入口**按钮(图、模型树、属性/校验、矩阵、文档);最右"生成文档"。
- **左栏 模型树**:户型 #1 → 客厅、主卧、次卧、厨房、卫生间、书房(每项前一个状态小圆点,红/黄/绿)。
- **中栏 户型画布**(主角):一套**示意户型平面**,房间是带圆角的方块,每个房间内显示:房间名 + 一个**派生芯片**(如"面积 20㎡""窗地比 0.14")+ 一个**规则灯角标**(暗区房间=红、通风/窗地比不足=黄、达标=绿)。让"次卧"亮红(采光不足)、"主卧"亮黄(通风弱),其余绿。
- **右栏 属性 / 校验**:选中"次卧"时显示:房间名 + 状态(已实例化·来源 人工绘制);**校验区**列规则灯(采光 阻断、窗地比 警示、通风 警示);**字段区**可编辑(长 3m、宽 3m、窗面积 0.8㎡、采光系数 1.5%、换气 1.0、设计温度 22℃);**派生区**只读(面积 9㎡、窗地比 0.09)。
- 做一个**交互**:用滑块/输入改"次卧"的宽,画布该房间的面积芯片和规则灯随之变化(体现"改一处全联动")。

**关键原则(务必体现)**:
- 一切皆可停靠面板;次要功能"入口→展开",不平铺堆按钮。
- **规则灯**用红/黄/绿三色一致表达(阻断/警示/达标)。
- **维度叠加**:切到"光",房间按采光好坏重新着色,但房间位置不动。
- 数据要**真实合理**(用上面给的户型/房间/字段数值),不要发明工具做不到的能力(不需要 3D 渲染、不需要真实照片)。

**产出**:4 屏高保真设计 + 工作台那屏的关键交互可点;给出用到的颜色/间距/字体 token,方便交给开发落地。

## (设计完成后)交回 Cowork 怎么用
1. 在 Claude Design 里**导出 HTML**(或截图)。
2. 把导出文件/截图发我,我会:提取 tokens(配色/间距/字体)+ 各屏组件结构 → 出**前端实现卡**(对齐真实 view/command 客户端)→ 交 Codex 落地。
3. 这样"设计→真前端"少绕弯;设计只定"长相和布局",接数据由实现卡完成。
