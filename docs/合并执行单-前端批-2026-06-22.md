## 冲突处置(diagram-panel.tsx / styles.css 为主)
- 基本是**加性**:各卡往 `<ReactFlow>` 加各自的 props(nodeTypes / onConnect / selection / Background / onNodeContextMenu …)和各自的样式 → **保留双方**。
- 留意:`<ReactFlow>` 标签上同一 prop **别重复**(各 prop 只保留一处);import 合并去重;`nodeTypes`(来自 skin 的 object-node)与各交互 handler 都要在。
- **拿不准就把冲突段(或整文件)贴给我,我给你合好的版本。**

## 某张红了 → 回滚那一张
```bat
:: 还在冲突中(没 commit):
git merge --abort
:: 已 commit 但 verify 红:
git reset --hard HEAD~1
```
回滚后把报错贴给我,修好再合。
