# P2 四卡 · 分支与合并操作(Windows cmd)

> 在 `E:\0.M-Next`(守 main)操作。用 **git worktree** 给四张卡各开一个独立文件夹并行跑,基线都从当前 main 起(避免上次"旧基线幻影删除"的坑)。

## 0. 前提
```bat
cd /d E:\0.M-Next
git checkout main
git status                         :: 确认干净、在 main
```

## 1. 建 4 个 worktree + 分支(并行用)
```bat
git worktree add E:\mnext-p2a -b feat/T-V33-web-p2a
git worktree add E:\mnext-p2b -b feat/T-V33-web-p2b
git worktree add E:\mnext-p2c -b feat/T-V33-web-p2c
git worktree add E:\mnext-p2d -b feat/T-V33-web-p2d
```
（每个都从当前 main 起步,互不影响。）

## 2. 每个 worktree 装依赖 + 发 Codex
```bat
cd /d E:\mnext-p2a && corepack pnpm install
cd /d E:\mnext-p2b && corepack pnpm install
cd /d E:\mnext-p2c && corepack pnpm install
cd /d E:\mnext-p2d && corepack pnpm install
```
分别让 Codex 在对应文件夹按对应卡实现:
- `E:\mnext-p2a` ← `docs/tasks/T-V33-WEB-P2a-选择右键快捷键.md`
- `E:\mnext-p2b` ← `docs/tasks/T-V33-WEB-P2b-排布对齐吸附网格.md`
- `E:\mnext-p2c` ← `docs/tasks/T-V33-WEB-P2c-连线增强.md`
- `E:\mnext-p2d` ← `docs/tasks/T-V33-WEB-P2d-命令面板.md`

## 3. 完工要求(交给 Codex 的硬指令,治"没提交"老毛病)
每张在自己 worktree 里必须:
```bat
corepack pnpm verify                       :: 全绿
git add -A && git commit -m "feat(web): <卡名> (T-V33-WEB-P2x)"
git log --oneline -1                        :: 确认看到这条 feat 提交,不是旧 tag
git diff --stat main                        :: 只应有本卡文件
```
**不提交不算完成**;`git diff --stat main` 若冒出非本卡文件/docs 删除 → 是基线没拉平,先 `git merge main` 再说,别提交那些。

## 4. 合并回 main(一次一张,每张合前拉平)
> ⚠️ **P2a / P2b / P2c 都改 `diagram-panel.tsx` 和 `styles.css`,并行后第 2、3 张合并会在这两个文件撞**(多是加性冲突,保留双方即可)。**P2d 改 `workbench.tsx`+新文件,基本独立。**
> 建议顺序:**先合独立的 P2d → 再 P2b → P2a → P2c**(改 diagram-panel 的三张串着合,每张先 `merge main` 拉平解冲突)。

```bat
:: —— 以 P2d 为例(独立,先合)——
cd /d E:\mnext-p2d && git merge main && corepack pnpm install && corepack pnpm verify
cd /d E:\0.M-Next && git merge --no-ff feat/T-V33-web-p2d && corepack pnpm verify

:: —— P2b(改 diagram-panel,合前拉平)——
cd /d E:\mnext-p2b && git merge main
::   若 diagram-panel.tsx / styles.css 冲突 → 编辑解决(保留双方改动)→ git add . && git commit
cd /d E:\mnext-p2b && corepack pnpm install && corepack pnpm verify
cd /d E:\0.M-Next && git merge --no-ff feat/T-V33-web-p2b && corepack pnpm verify

:: —— P2a(同法,再拉平再合)——
cd /d E:\mnext-p2a && git merge main
cd /d E:\mnext-p2a && corepack pnpm install && corepack pnpm verify
cd /d E:\0.M-Next && git merge --no-ff feat/T-V33-web-p2a && corepack pnpm verify

:: —— P2c(最后)——
cd /d E:\mnext-p2c && git merge main
cd /d E:\mnext-p2c && corepack pnpm install && corepack pnpm verify
cd /d E:\0.M-Next && git merge --no-ff feat/T-V33-web-p2c && corepack pnpm verify
```
每张合后在 main 上 `corepack pnpm verify` 必须全绿再进下一张。

## 5. 清理(每张合完即清)
```bat
git worktree remove E:\mnext-p2d
git branch -d feat/T-V33-web-p2d
:: 其余 p2b/p2a/p2c 同样
```

## 冲突处置速记
- `diagram-panel.tsx` / `styles.css` 冲突基本是**加性**(各卡加各自的 handler/样式)→ 保留双方,留意 `<ReactFlow>` 标签上的 props 别丢、别重复。
- 撞了拿不准就把冲突段贴给我,我给你合好的版本(像之前 check-contracts 那样)。
- 任何"夹带的越界文件 / docs 删除" → 不提交,回报。
