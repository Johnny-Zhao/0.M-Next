## 0. 角色与任务

## 1. 产品定位(必须贯穿每一屏)

**M-Next 是"统一真值的多重表达引擎"。** 一份工程真值,可在**不同工具语言、不同设计阶段、不同分析维度**之间自由表达,平台保证这些表达**彼此一致**。

- 一句话:**一处真值,处处表达;表达之间永远对得上。**
- 它不是更聪明的数据库,也不只是数据集线器——它的灵魂是"**同一个东西,换一种说法看,还能对得上**"。
- 它是**底座 + 可插拔领域 profile**:卫星总体、室内建筑…都是同一底座上的 profile,套同一套壳。

**校核与比选是这个重心的两个侧面**(设计须如此组织,不要并列三个平权功能):
- **闭环校核 = 表达之间没掉队**(对不上 = 需要收敛的信号);
- **方案比选 = 在表达的变体里挑一个**。

## 2. 核心隐喻:表达切换台(本设计的主角)

选中一个**实体**(如"能源分系统"),界面顶部是一排**表达轴切换器**,沿三根轴移动观察同一份真值:

```
实体:能源分系统  PWR
┌───────────────────────────────────────────────────────────┐
│ 语言: [ SysML ▸ Modelica  Excel  3D ]   ← 翻译(可能有损)      │
│ 阶段: [ 方案  ▸初样◂  正样 ]            ← 细化(累加保真)      │
│ 维度: [ ▸能量◂  热  质量 ]              ← 投影(无损视图)      │
└───────────────────────────────────────────────────────────┘
```

切换任一轴,平台显式回答三件事:**映射了什么 · 哪里有损/过期 · 与别的表达对不对得上**。这"表达切换 + 映射透明 + 跨表达一致性"是产品门面,**优先级高于美化既有五镜头**。

## 2.5 总体视觉风格(统领所有屏 · 最重要)

**模型优先,数据作叠加(model-first, data-as-overlay)。** 每一屏都先呈现对象/表达最丰富的**可视化模型**(几何 / 框图 / 拓扑 / 3D / 热力图 / 图表),数据(字段、派生、规则)通过**叠加图层 + 图例 + 悬停检视器 + 瘦右栏**挂在模型上——**绝不把表格/卡片当门面**(那会让产品像个聪明数据库,失了灵魂;旧高保真稿正是错在"表格优先")。

- **模型浏览器**以 图(拓扑)/ 矩阵(热力)/ 3D 为主视;**树/表退为"精确读数与编辑"的辅助检视器**,不抢门面。
- **维度 / 语言 / 阶段切换 = 在同一模型上换叠加图层**(《城市天际线》信息视图:模型不变,只重绘图层)。
- **没有几何的对象** → 回退到**自动布局的拓扑图/框图**,仍以图形为主。
- **表格仍合理之处(配角,不是门面)**:对象字段精确编辑、报告预览、审计留痕、导入列映射——它们是模型的检视器/编辑器。
- 工程含义:每个对象类型 / profile 需有**默认可视化**(有几何用几何,无几何用拓扑/示意);设计需给出这套回退策略的样子。

## 3. 三根表达轴(性质不同,UI 处理不同)

| 轴 | 含义 | 关系性质 | UI 处理 | 后端就绪度 |
|---|---|---|---|---|
| **维度轴** | 同一对象看哪个物理侧面(能量/热/质量;风/热/光) | **投影/选取,无损** | **像《城市天际线》信息视图**:同一模型视图(2D 图/3D/热力)上**只换叠加图层**(热力/流线/等值线),瞬时;数据退为图例+悬停,**不是字段卡** | 现成 → **首批 demo** |
| **阶段轴** | 同一实体的成熟度(方案→初样→正样) | **细化,累加** | 同一实体跨阶段 profile 建链 + 阶段 diff + 血缘回溯 | profile/联邦撑一部分,需补阶段链/ diff |
| **语言轴** | 用哪个工具的形式语言说(SysML/Modelica/Excel/3D) | **翻译,可能有损,需往返对账** | 表达并排 + 映射表 + 有损/未实现标注 | 入向适配已有(sysml/reqif/json);**双向投影、Modelica 为后续** |

> **一句话区分:维度=选取(无损)、阶段=细化(累加)、语言=翻译(可能失真)。**
> **重要约束(语言轴):** SysML→Modelica 双向语义投影、Modelica 本体属"研究级/后续"。UI 对尚未实现的出向/往返,要**明确标注为"投影预览 / 只读映射 / 待接入"**,不得画成"已能双向同步"。入向(把外部表达导入统一真值)是当前能力的重点。

## 4. 跨表达一致性(核心价值回路,必须有专门界面)

魔法时刻不是看到一个派生值,而是**发现两个表达对不上,并被帮着判断这意味着什么**:

> SysML 标称母线功率 **120 W**,Modelica 仿真得 **135 W**。
> 平台要呈现并引导判别:这是 **① 真不一致(设计未收敛 → 去校核/迭代)** 还是 **② 口径误差(边界条件/单位/取整不同 → 去对齐映射)**?

一致性是第一类公民:**并排差异 + 差值/百分比 + 判别线索(口径/单位/时间戳/来源)+ 一键发起校核或重投影**。这就是闭环校核在本重心下的真正形态——不是"规则灯变红",而是"**表达之间出现裂缝**"。

## 5. 目标用户

1. **工程师 / 分析师**:在表达轴间移动、建模、跑分析、看派生与一致性裂缝。
2. **评审 / 负责人**:看一致性结论、推荐、风险,确认出件。
3. **Profile 作者 / 管理员(进阶)**:配类型/字段/关系/规则/权重/派生/维度集/阶段链(可二级界面)。

## 6. 核心概念(都要在 UI 体现,且贴合后端)

- **工作空间 workspace**:一个项目/一套数据,基于某 **profile** 实例化。
- **对象 / 字段**:有类型(可泛化父子)、字段、关系;字段分**存储值**与**派生值**(后端实时计算,如综合分/面积/容量裕度)——UI 必须区分(派生值带 `fx` 芯片 + 浅底 + "后端实时")。
- **关系**:有类型、方向、状态(ACTIVE/UNLINKED);跨对象互引、**互引不互拷**。
- **规则**:校核产生 **WARN(告警)** 或 **BLOCK(一票否决)**;可跑检查批次,结果按对象/字段归档(`runId`)。
- **provenance(贯穿所有表达的视觉常量)**:每个值都带"护照"——**来源**(工具/手填/导入/派生)、**新鲜度**(updatedAt/陈旧标记)、**下游依赖数**。点开抽屉看"由哪条规则/哪次分析/哪份输入算出"。
- **五镜头(同一份数据的通用看法,退为支撑)**:树/表/图/矩阵/文档——是"读统一模型"的方式,**不是表达轴**,不再当门面。
- **命令(CQRS)**:所有写操作经命令入口,读写分离;**改一处 → 派生/规则实时重算**(`recomputing` 态)。
- **分析(引擎,可插拔)**:仿真(能源 SOC 曲线)、决策方法(**TOPSIS / AHP / WPM**)。
- **推荐**:对候选按方法排序给推荐+备选,方法 = **加权和 / TOPSIS / AHP / WPM**;切方法即时改排名;无该方法运行时引导"先跑一次"。
- **联邦 / M2M 投影**:跨 profile 对应(同一实体多镜头互引)+ 模型到模型投影——**这是阶段轴/语言轴的底层机制**。
- **接入 / 导入(表达的进水口)**:ExchangeAdapter(json/reqif/sysml 解析)+ Excel 导入(映射驱动、≤50MB、xlsx 白名单)。每种适配是"把外部表达引入统一真值"的一根管子。
- **附件**:对象可挂报价单/图纸等(两步:先传 blob 再挂对象),只留取关联、不解析内容(≤50MB、白名单、≤50/对象)。
- **快照 / 导出**:取快照锁口径 → 渲染报告,导出 **docx/pdf/xlsx/html/md/csv**。
- **AI 治理变更集**:AI **不直接写**,只提"可审查变更集"(propose → 人 confirm → 经命令落库、留审计)。AI 角色 = **表达一致性守门人**。
- **RBAC**:四档 VIEWER<AUTHOR<REVIEWER<ADMIN;编辑/确认按角色门控。

## 7. 信息架构 / 导航壳

- **顶栏**:M-Next 标志 + `DATA HUB` 单色徽标(Mono);工作空间切换 + 当前 **profile** 指示;全局搜索 + **命令面板 ⌘K**;**编辑模式**开关(按 RBAC 角色启用);用户/头像。
- **左栏(~280px)**:
  - 工作空间(名 + profile);
  - **导航**:① **实体工作台(表达切换台)←主入口** ② 模型浏览器(五镜头) ③ 一致性中心 ④ 血缘/接入 ⑤ 分析运行器 ⑥ 比选 ⑦ 报告导出;
  - **对象类型** + 数量徽标。
- **主区**:默认**实体工作台(表达切换台)**;或五镜头/对象详情/分析运行器/一致性对比。
- **右栏(~320px,常驻「实时结论」)**:选中对象的派生值(fx)+ 规则告警灯(BLOCK/WARN)+ **provenance 护照** + **当前表达一致性状态** + 附件;未选中时显示工作空间级一致性裂缝汇总 + 报警灯 + 推荐 Top。

## 8. 关键界面(按优先级,线框 → 高保真)

> 以"卫星总体"为主样例(下方第 9 节给具体数据),"室内建筑(房子)"为副样例证明 profile 复用。

1. **实体工作台 / 表达切换台(门面,最高优先)**
   顶部三轴切换器(语言/阶段/维度)+ 中央"当前表达"画布(随轴变形:维度=字段/规则子集面板;阶段=该成熟度快照;语言=该形式语言渲染或映射预览)+ 右栏实时结论。切换时顶部出"**映射条**":映射了什么、有损/过期标记、与默认表达的一致性徽标。
2. **维度轴视图(首批 demo,务必高保真)——像《城市天际线》信息视图**
   中央是一张**模型视图**(户型平面图 / 卫星框图 / 3D),切 `能量·风 / 热 / 质量·光` 时**模型几何不动,只重绘叠加图层**:热力填色 / 流线 / 等照度线 / 部件着色 + 色带图例。数据(派生/规则)退为图例 + 悬停 tooltip + 右栏一行结论。**严禁做成字段卡清单。**(详见 `平台UI-维度轴单屏-ClaudeDesign.md`)
3. **跨表达一致性对比(核心价值,务必高保真)**
   左右并排两个表达(如 SysML vs Modelica,或 方案 vs 初样),逐字段对照:相等(灰)、不一致(红,带差值/%)、缺失/未映射(虚线)。每条不一致给"**真不一致 / 口径误差**"判别提示 + 来源/时间戳 + 操作(发起校核 / 重投影 / 标注接受)。
4. **血缘 / provenance(集线器骨架)**
   选中一个值 → 血缘图:上游(来源工具/导入/手填 + 新鲜度)→ 本值(哪条派生/规则)→ 下游(依赖它的规则/比选/其它表达)。含"陈旧链路"高亮(基于过期数据的下游)。
5. **模型浏览器(五镜头,退为支撑)**
   树/表/图/矩阵/文档,一键切换、选择跨镜头联动;表镜头列含派生值(fx)+ 规则状态徽标;图镜头支持联邦对应高亮。**作为"读统一模型"的方式,不抢门面。**
6. **对象详情 / 编辑**
   字段区(存储 vs 派生不同样式)、关系区、规则状态、provenance 抽屉、附件区(拖拽上传/关联/查看/移除)、命令动作区(创建/改/跑分析/导出);编辑按 RBAC 角色启用。
7. **分析 / 方法运行器**
   选引擎(仿真 SOC / 决策 TOPSIS·AHP·WPM)→ 配参数(指标/权重/方向 benefit·cost / 两两比较矩阵)→ 跑 → 结果 + 图表(SOC 曲线 / 雷达 / 柱状)→ 回灌模型 + 落运行记录。
8. **推荐(四方法)**
   选方法 `加权和 / TOPSIS / AHP / WPM` → 推荐对象 + 备选排名 + 理由;切方法即时改排名;无运行引导"先跑一次"。**(注意:务必含 WPM,共四方法。)**
9. **接入 / 导入管理(表达进水口)**
   适配器/管子列表(Excel / SysML / ReqIF / JSON …)+ 接入状态 + 最近同步时间 + 新鲜度;Excel 导入向导(上传 ≤50MB、xlsx 白名单 → 列映射 → 预检 → 落 DRAFT 对象 + 行级错误回显)。
10. **联邦 / M2M 投影**
    对应互查(此 profile 对象 ↔ 彼 profile 对象)、投影预览;**出向/往返未实现处标注"预览/待接入"。**
11. **报告 / 导出**
    取快照(锁口径)→ 报告预览 → 选格式导出 `docx/pdf/xlsx/html/md/csv`。
12. **领域样例「比选」(证明 profile + 壳)**
    评分工作台(候选×指标可编辑评分矩阵、理由气泡、热力着色、底部实时综合分)、指标与权重(分组 + **100% 合计校验条**,≠100% 红色阻断)、结果分析(对比表 + **雷达** + **柱状排名** + 推荐卡 + 风险面板)、**一票否决**(命中候选置灰+删除线+排名下沉+不推荐)。
13. **AI 一致性守门人(右栏/抽屉)**
    AI 主动提示:"热分析数据比电源旧 3 天,此余量可能不一致""蓄电池容量手填且无来源,建议接入电池工具""两工具对同一接口报不同值"。每条 = 可审查**变更集**(propose),由 REVIEWER **confirm** 后才经命令落库;BLOCK 项跳过。**严禁画成 AI 直接改数据。**
14. **(进阶)Profile 作者台**:类型/字段/关系/规则/派生/权重/**维度集**/**阶段链** 配置;模板另存复用。
15. **审批 / 留痕**:操作时间线 + 结果确认锁定。

## 9. 样例数据(供高保真使用,使画面真实)

**主样例 · 卫星总体 / 能源分系统(PWR)** —— 子项:太阳电池阵 SA、蓄电池组 BAT、电源控制器 PCU。
- 维度轴:**能量**(总容量 78 Ah、放电深度 DOD 62%、能量余量 −4.2%、寿命余量 1.8 yr)/ **热**(电池温度,阴影区接近下限 −8°C WARN)/ **质量**(质量预算)。
- 规则灯:`BLOCK R-PWR-03 能量余量<5% 设计要求`(红/阻断);`WARN 阴影区温度接近下限`(橙)。
- 阶段轴:方案(母线功率预算 120 W,余量 +6%)→ 初样(详细组件,余量 −4.2%)→ 正样(实测 DOD 62%)。
- 语言轴:SysML(结构块+端口)/ Modelica(功率平衡 + SOC 状态方程)/ Excel(功率预算表)/ 3D(布局)。
- **一致性裂缝示例**:SysML 母线功率 120 W vs Modelica 仿真 135 W(+12.5%)→ 判别提示"真不一致:设计未收敛"。
- 推荐/比选样例:**蓄电池方案比选**(候选:锂离子 / 镉镍 / 氢镍;镉镍命中一票否决 → 置灰淘汰)。

**副样例 · 室内建筑(房子)** —— 同一几何,维度轴 **风(CFD 风环境)/ 热(U 值·能耗)/ 光(采光系数 DF)**,证明"换 profile、同一套表达切换壳"。

## 10. 关键交互

- **表达轴切换**:点轴 → 画布与右栏即时变形;顶部映射条显示映射/有损/过期 + 一致性徽标;无损(维度)瞬时,翻译(语言)给"投影中/预览"态。
- **改即重算**:改字段/选型/权重/评分 → 派生与规则实时重算(乐观更新 + `recomputing` → 最终态)。
- **一致性判别**:点裂缝 → 并排差异 + "真不一致/口径误差"线索 + 发起校核/重投影/标注接受。
- **provenance 溯源**:点任意值 → 血缘抽屉(上游来源·新鲜度 / 本值规则·派生 / 下游依赖)。
- **命令面板 ⌘K**:驱动所有写操作(创建/改/建关系/跑分析/导入/上传/导出)。
- **选择联动**:跨镜头/跨表达同步选中 + 联邦对应高亮。
- **方法切换**:推荐页 加权和/TOPSIS/AHP/WPM 即时改排名。
- **权重校验条**:合计 ≠100% 红色并阻断"开始比选/确认"。
- **导入向导**:大小/类型校验 → 列映射 → 预检 → 行级错误回显。
- **冲突**:并发编辑版本冲突对话框(乐观锁失败)。
- **确认 / 审批**:满足前置(权重 100%、无未评必填、无未决否决、按角色)方可确认;确认后锁定 + 留痕;AI 变更集需 REVIEWER 确认。

## 11. 状态(每个数据界面都要覆盖)

`default` / `loading`(骨架) / `empty`(引导建模,逐屏文案如"暂无候选,添加第一个") / `error`(可重试) / `success`(toast),外加:
- **`recomputing`** 派生计算中;
- **`blocked`** 规则一票否决(红 + 阻断);
- **`inconsistent`** 表达间裂缝(并排红差值);**`stale`** 基于过期/陈旧来源(琥珀链路);
- **`lossy` / `unmapped` / `not-implemented`** 语言轴投影有损 / 未映射 / 出向待接入(虚线 + 标注);
- `conflict` 并发冲突;`offline`。

## 12. 视觉语言 + 设计令牌(由你设计)

**令牌交给你设计**,基调走**现代 Microsoft Office / Fluent 设计语言("Office 2026"方向)**:干净明亮、柔和材质与适度圆角、留白充分、克制装饰、**单一强调色 + 成体系的中性灰阶**、清晰层级;桌面高密度但不拥挤。请自行产出完整 token(色 / 字 / 间距 / 圆角 / 语义色 / 暗色),**不必沿用任何预设 hex**。

硬约束(令牌自由,但须满足):

- **语义色成体系且稳定、四态可辨**:通过/达标、告警 WARN、阻断 BLOCK、陈旧/有损;**色彩非唯一信息载体**(必配图标/形状/文案)。
- **统一标记**:派生值用统一芯片(如 `fx`);否决态统一灰 + 删除线;裂缝/陈旧有统一视觉(差值徽标 / 时钟标)。
- **字体**:正文系统无衬线(可取 Segoe 类 Office 观感);**代码 / 单位 / 标识符 / 方程用等宽**。
- **亮 / 暗双主题**齐全。
- **模型画布的物理热力叠加用物理色带**(冷→暖、低→高),物理场景不随主题反相;框架(轴切换器/右栏/徽标)随主题。
- 强层级与对比,**模型为主、数据为辅**的信息密度。

## 13. 数据 / 技术约束(设计须可落到现有后端之上)

- **读写分离**:视图只读;**写一律经命令入口**(按钮/⌘K 触发),**UI 不发明新写路径**。
- 已有 **REST 能力面**(据此组织,不必精确到 JSON):
  - 命令:对象(创建/改字段/建关系)、元模型(模板/类型字段关系/发布/实例化)、规则(定义/发布/跑检查)、附件(传 blob / Attach / Detach)、评审/审批、**RBAC 授权**、**导入解析**、**AI 变更集(propose/confirm/reject)**;
  - 视图(只读、有界):对象/树/表/矩阵/图(联邦对应)、**推荐 `?method=weighted|topsis|ahp|wpm`**、规则检查结果 `?runId`、附件列表 `?objectId`、派生求值、快照、同步状态;
  - 分析:提交仿真/决策运行(`engineId` = `energy-soc` / `decision-topsis` / `decision-ahp` / `decision-wpm`)→ 读运行结果;
  - 接入:ExchangeAdapter 解析(json/reqif/sysml)、Excel 导入(映射 → DRAFT 对象);
  - 导出:快照 → 渲染 `docx/pdf/xlsx/html/md/csv`。
- **派生/规则/一致性来自后端实时计算**,UI 负责呈现 + `recomputing`。
- 已有前端**视图 SDK(树/表/图/矩阵/文档/详情/冲突对话框/选择联动)**;**表达切换台、一致性对比、血缘图、图表(SOC/雷达/柱状)、附件拖拽、导入向导** 为新增前端能力(本设计涵盖)。
- **能力就绪度边界(务必标注)**:维度轴=现成;阶段轴 diff/链=部分(可设计但标"接入中");语言轴**入向**可用,**双向投影/Modelica=后续**(画为预览/只读/待接入)。
- 有界:列表/候选有上限(候选 ≤500、附件 ≤50/对象、文件 ≤50MB、导入 ≤5000 行),设计含"超限/截断"提示。
