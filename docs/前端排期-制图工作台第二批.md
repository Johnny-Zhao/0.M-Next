## 依赖与并行建议

- **可立刻并行(纯前端、无契约)**:P2a / P2b / P2c / P2d、P3b、P4a→P4b、P4c、P5b、P5c。
- **需先补 view-API(人发起契约,先出后端设计稿)**:P3a(血缘)、P3d(规则灯)、P3c(维度集)、P3e(跨表达比对)、P5a(子图)、P5d(批注多粒度)。→ **建议先做一张"视图 API 扩展(血缘/规则/维度/批注)"后端设计稿**,把 P3/P5d 的契约一次理清。
- **重型、单列评估**:P5e 实时协同(后端实时通道)、P6 各高级域。

## 推荐推进顺序

1. **P1**(进行中)→ 2. **P2 全四张**(把图做好用,纯前端可并行)→ 3. **P4a/P4b/P4c**(分析/比选/导出,后端已就绪,见效快)→ 4. 出**"视图 API 扩展"后端设计稿** → 5. **P3 全套**(派生/provenance/3D/维度/一致性,M-Next 之魂)→ 6. **P5a/b/c**(大模型导航)→ 7. **P5d 批注、P6 高级域**按业务排。

> 每张卡到点再细化为封闭卡(范围/封闭文件清单/红线/验收),不提前展开,避免空转。
