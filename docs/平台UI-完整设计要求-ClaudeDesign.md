## 角色与任务

你是资深产品设计师。为「统一数据驱动办公平台 M-Next」设计**完整 UI**:信息架构、组件系统、关键屏(线框 → 高保真)、全状态、开发 handoff 规格。**桌面优先,中文(zh-CN)为主,亮/暗双主题。** 气质:工具感、数据优先、克制装饰、高信息密度但不杂乱(参考 Linear / Retool / 数据建模工具,非营销站)。

## 产品定位(必须贯穿设计)

M-Next 是**多专业工程分析集线器(hub)**:收集各专业工具的数据 → 统一建模呈现 → 做跨专业综合分析与闭环校核。它**不是单一工具,而是底座 + 可插拔领域插件(profile)**。一句话:**一份数据、多个工程镜头(树/表/图/矩阵/文档)、互引不互拷;专业求解外挂,综合与追溯在平台。** 领域工具(比选、卫星能源、室内设计…)都是同一底座上的 profile,套同一套 UI 壳。

## 目标用户

1. **工程师 / 分析师**:建模、切多镜头、跑分析、看派生与告警。
2. **评审 / 负责人**:看结论、推荐、风险,确认出件。
3. **Profile 作者 / 管理员(进阶)**:配类型 / 字段 / 关系 / 规则 / 权重 / 派生(可作二级界面)。

## 核心概念(都要在 UI 体现)

- **工作空间(workspace)**:一个项目 / 一套数据,基于某 **profile(领域模板)** 实例化。
- **对象**:有类型(可泛化父子类型)、字段、关系;字段分**存储值**与**派生值(后端实时计算,如加权综合分、面积、容量裕度)**——UI 必须区分二者。
- **关系**:有类型、方向、状态(ACTIVE/UNLINKED);跨对象互引。
- **规则**:校核产生**告警(WARN)**或**一票否决(BLOCK)**;可手动跑检查批次,结果按对象/字段归档。
- **五种视图(同一份数据的只读镜头)**:树(层级)、表(列表,列含派生值 + 规则状态)、图(关系网络/拓扑/联邦对应)、矩阵(行列交叉,如候选 × 指标)、文档(结构化呈现)。
- **命令(CQRS)**:所有写操作经命令入口,读写分离;**改一处 → 派生/规则实时重算**。
- **分析(引擎)**:外接/内置引擎跑结果 → 回灌模型 → 可视化。已实现引擎:**仿真**(能源 SOC 曲线)、**决策方法**(TOPSIS、AHP);方法可插拔。
- **推荐**:对一个项目的候选,按"方法"排序给推荐 + 备选;方法可选 **加权和 / TOPSIS / AHP**。
- **联邦**:跨 profile 对应(同一实体多镜头互引)+ M2M 投影。
- **附件**:对象可挂报价单/方案/图纸等文件(两步上传:先传 blob、再挂对象),只存取关联留痕、不解析内容。
- **模板 / 审计 / 审批**:profile 可存模板复用;所有操作留痕;结果确认后锁定。
- **快照 / 导出**:对数据取快照 → 渲染报告,支持 **docx / pdf / xlsx / html / markdown / csv** 多格式导出。

## 设计原则

数据优先、克制装饰;**统一壳 + 多镜头**;**闭环反馈**(改即重算、即校核);**可追溯**(每个派生值/结论可溯源:由哪条规则、哪次分析、哪份输入算出);告警用语义色;桌面高信息密度。

## 信息架构 / 导航壳

- **顶栏**:工作空间切换、全局搜索 + **命令面板(⌘K)**、当前 profile / 模式指示、用户。
- **左栏**:工作空间内导航(对象类型 / 视图 / 分析 / 报告 / 附件 / 设置)。
- **主区**:当前镜头(树/表/图/矩阵/文档)或对象详情或分析运行器。
- **右栏(常驻「实时结论」)**:选中对象的派生值 + 规则告警灯 + provenance + 附件;未选中时显示工作空间级报警汇总 + 当前推荐 Top。

## 关键界面(按优先级,出线框 + 高保真)

1. **工作台 / 总览**:工作空间概况、四阶段流程(建模 → 校核 → 分析 → 出件)、报警灯、最近项、快捷入口、当前推荐 Top。
2. **模型浏览器(五镜头)**:树/表/图/矩阵/文档,**一键切换、选择跨镜头联动**(选中对象在各镜头同步高亮),图镜头支持联邦对应高亮。表镜头列含派生值与规则状态徽标。
3. **对象详情 / 编辑**:字段区(**存储 vs 派生不同样式**)、关系区、规则状态、历史 / provenance 抽屉、**附件区(拖拽上传、关联、查看、移除)**、命令动作区(创建/改/跑分析/导出)。
4. **分析 / 方法运行器**:选引擎(仿真 SOC / 决策方法 TOPSIS / AHP)→ 配参数(指标/权重/方向/两两比较矩阵)→ 跑 → 看结果 + 图表(SOC 曲线 / 雷达 / 柱状)→ 结果回灌模型 + 落运行记录。
5. **推荐**:选方法(**加权和 / TOPSIS / AHP**)→ 看推荐对象 + 备选排名 + 推荐理由;切方法即时改推荐;无方法运行时引导"先跑一次该方法"。
6. **联邦 / 投影**:对应互查(此镜头对象 ↔ 彼镜头对象)、M2M 投影预览。
7. **报告 / 导出**:取快照 → 报告预览 → 选格式导出(**docx / pdf / xlsx / html / md / csv**)。
8. **附件管理**:文件列表(名称/类型/大小/上传人/时间)、上传(校验大小≤50MB / 类型白名单)、关联到对象或评分项、下载、软删;附件数上限提示。
9. **领域样例「比选」**(证明"工具 = profile + 壳",**首批落地高保真**):
   - **评分工作台**:候选 × 指标可编辑评分矩阵(人工/自动分、理由气泡、得分热力着色)、底部实时综合分预览;
   - **指标与权重**:指标分类分组、权重输入 + 醒目的 **100% 合计校验条**(≠100% 红色阻断);
   - **结果分析**:对比表 + **雷达图**(多候选能力轮廓叠加)+ **柱状综合分排名榜** + 推荐卡(含理由)+ 风险面板;
   - **一票否决**:命中否决的候选**置灰 + 淘汰标记**、排名下沉、推荐不选;风险项以徽标挂候选/单元格并汇总到风险面板;
   - 项目总览:四阶段进度 + 报警灯 + 关键数。
10. **(进阶)Profile 作者台**:类型 / 字段 / 关系 / 规则 / 派生 / 权重 配置(可二级界面);模板另存与复用。
11. **审批 / 留痕**:操作记录时间线 + 结果确认锁定。

## 关键交互

- **改即重算**:改字段/选型/权重/评分 → 派生与规则**实时重算**(乐观更新 + 投影延迟的 `recomputing` 态 → 最终态);
- 规则 **BLOCK → 阻断 + 红**;**WARN → 徽标 + 右栏汇总**;
- **命令面板(⌘K)** 驱动所有写操作(创建/改/跑分析/导出/上传);
- **选择联动**:跨镜头同步选中 + 联邦对应高亮;
- **provenance 溯源**:点派生值/结论 → 抽屉展开"由什么算的(哪条规则/哪次运行/哪份输入)";
- **方法切换**:推荐页 加权和/TOPSIS/AHP 即时改推荐与排名;
- **附件**:拖拽上传 → 自动校验(大小/类型/sha256)→ 关联;审查时一键查看/下载;
- **权重校验条**:合计 ≠100% 红色并阻断"开始比选/确认";
- **冲突**:并发编辑版本冲突对话框;
- **确认 / 审批**:满足前置(权重 100%、无未评必填、无未决否决)方可确认;确认后锁定 + 留痕。

## 状态(每个数据界面都要覆盖)

`default` / `loading`(骨架) / `empty`(引导建模) / `error`(可重试) / `success`(toast),外加 **`recomputing`(派生计算中)**、**`blocked`(规则阻断)**、`conflict`(并发冲突)、`offline`。逐屏给空态引导文案(如"暂无候选,添加第一个")。

## 视觉语言

专业、克制、数据优先;强层级与对比;**语义色**(红=阻断/风险、橙=告警、绿=通过/达标);**派生值用区别样式**(带 `fx` 标 / 斜体 / 浅底芯片);否决态用灰 + 删除线;亮/暗双主题;桌面优先(高密度),平板次之;中文为主、可国际化。

## 数据 / 技术约束(遵守,设计须可落到现有后端之上)

- **读写分离**:视图只读;**写一律经命令入口**(按钮/命令面板触发),**UI 不发明新写路径**;
- 已有 **REST 能力面**(设计据此组织,不必精确到 JSON):
  - 命令:对象(创建/改字段/建关系)、元模型(建模板/定义类型字段关系/发布/实例化)、规则(定义/发布/跑检查)、附件(传 blob / AttachFile / DetachFile)、评审/审批;
  - 视图(只读、有界):对象/树/表/矩阵/图(联邦对应)、**推荐 `?method=weighted|topsis|ahp`**、规则检查结果 `?runId`、**附件列表 `?objectId`**、派生求值、快照;
  - 分析:提交仿真/决策运行(`engineId` = `decision-topsis` / `decision-ahp` / `energy-soc`)→ 读运行结果;
  - 导出:快照 → 渲染(**docx/pdf/xlsx/html/md/csv** 已具备);
- 派生/规则来自后端实时计算,UI 负责呈现 + `recomputing` loading;
- 已有前端**视图 SDK(树/表/图/矩阵/文档)**;**图表(SOC 曲线/雷达/柱状)与附件拖拽上传**为新增前端能力(本设计内涵盖);
- 有界:列表/候选有上限(如候选 ≤500、附件 ≤50/对象、文件 ≤50MB),设计需含"超限/截断"提示。

## 可访问性 & 响应式

键盘可达(尤其表/矩阵单元格、评分录入);**色彩非唯一信息载体**(告警/否决配图标);对比度 WCAG AA;桌面优先,关键页响应式收窄;大候选/多指标时矩阵的虚拟滚动与列冻结。

## 交付物

1. 信息架构图 + 导航壳;
2. 设计语言 / token(色/字/间距/语义色/暗色);
3. **组件库**:表、图、矩阵、树、文档、卡、徽标、**派生值芯片(fx)**、规则状态灯、**provenance 抽屉**、命令面板、**附件上传卡**、状态占位、**图表(曲线/雷达/柱状)**、**权重 100% 校验条**、推荐卡、风险面板、方法切换器、确认/审批条、导出格式选择器;
4. **关键屏高保真**:总览、五镜头、对象详情(含附件区)、分析/方法运行器、推荐(三方法)、联邦、报告导出、附件管理、**比选样例(评分工作台 + 结果分析)**;
5. 全状态规格(见「状态」);
