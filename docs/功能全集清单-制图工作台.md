## 结论与用法

1. **诚实结论**:此前确实漏了 **A(画布编辑)/ B(大模型导航)/ C 的多人协同与多粒度批注**——而其中"对齐、端口、下钻、批注、协同"说明书本就要求。本清单补齐,作为**总账**。
2. **大量 A/B 项是制图引擎/布局库自带或半自带**(React Flow + dockview),不必从零造;真正要自建的是"撤销栈、对齐分布、下钻子图、自动布局、右键/快捷键、批注锚点、命令面板"等。
3. **入口落位交给 Design**(定稿 §3bis:可扩展项一律"入口→展开",不平铺;放页眉/侧栏/右键/⌘K 由 Design 定)。
4. **P1 不变**:先把"壳 + 图画布 + 改即重算"跑通;A/B 的画布编辑能力,大部分随 React Flow 引入即获得,缺的(撤销/对齐/下钻/快捷键)按本清单在后续卡逐条补。
5. 本清单即**前端补全的待办池**:每条可转成封闭卡,按价值/依赖排期。
