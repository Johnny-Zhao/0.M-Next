# 阶段5 交互线框 v1 — 工作台 / 表格视图 / 选择联动

- 用途:阶段5(T-V33-2xx 系列)的设计输入与验收对照;依据:契约 §3.2/§5.3、说明书 6.12/8.2/8.4.1/9.2、AG-101/102/202/209
- 约定:本文档的交互规则条目编号 `W-x.y`,任务卡可直接引用;界面仅定结构与行为,视觉风格阶段5 用 Ant Design 默认即可

## 1. 工作台壳(WB)

```
+--------------------------------------------------------------+
| M-Next  | 工作空间: [技术方案A ▾]          [用户] [同步状态●] |
+----------+---------------------------------------------------+
| 视图栏    |                                                   |
|  ▸ 表格   |              < 当前视图渲染区 >                    |
|  ▸ 文档*  |                                                   |
|  ▸ 图形*  |                                                   |
+----------+---------------------------------------------------+
| 状态栏: 最后保存 12:03:21 | 待同步事件 0 | 错误 0              |
+--------------------------------------------------------------+
```

- W-1.1 工作空间切换即切换全部数据范围与权限范围(契约 P0);切换时视图区整体重载,禁止跨空间残留选择态。
- W-1.2 「同步状态●」三态:绿=读模型已追平 / 黄=同步中(显示落后事件数)/ 红=投递异常。最终一致的延迟必须**可见**,防止被当成 bug(总控阶段5 风险项)。
- W-1.3 带 * 的视图为后续阶段占位,置灰不可点,悬停提示"规划中"。

## 2. 表格视图(TB)

```
| # | 名称⇅        | 状态     | 负责人   | 预算(万) | 版本 |
|---|--------------|----------|----------|----------|------|
| 1 | 需求分析     | 已确认🔒 | 张三     | 12.0     | v5   |
| 2 | 方案编制     | 草稿     | 李四     | [8.5__]✎ | v3   |  ← 行选中高亮
| 3 | 评审准备     | 待确认   | —        | 3.0      | v2   |
+--------------------------------------------------------------+
| [+ 新增对象]                 第1/3页  共3条  [加载更多(虚拟滚动)] |
```

- W-2.1 行=对象、列=字段(由 object_type/field_def 驱动,非硬编码);列头排序/筛选仅作用于当前已加载范围,带分页参数请求(AG-202:pageSize≤200)。
- W-2.2 单元格双击进入编辑(✎);**本地即时回显**(8.2:300ms),右上角出现微型旋转图标表示后台保存中;提交载荷带该字段 expectedFieldVersion(契约 §5.4 字段级版本)。
- W-2.3 保存结果三态:成功→图标消失、版本列 +1;冲突→单元格红框 + 打开冲突弹层(§4);其他错误→单元格黄框 + 状态栏错误计数 +1,悬停显示业务语言文案(W-5.1)。
- W-2.4 终态对象(已确认/已归档/已废止)整行显示 🔒,编辑入口禁用,悬停提示当前状态与所需操作(如"需先转为有问题状态")。
- W-2.5 「新增对象」打开右侧抽屉表单(字段=该类型必填字段),提交即 CreateObject;500ms 内前台反馈(8.2),行以"待同步"样式插入顶部,事件追平后转正常样式。

## 3. 详情面板与选择联动(DP)

```
表格区(60%)                    | 详情面板(40%)
                               | ▎方案编制            [草稿] v3
  (选中行2)  ───────────────▶  | ─ 字段 ─────────────────
                               |  负责人: 李四
                               |  预算:   8.5 万   ✎
                               | ─ 关系 ─────────────────
                               |  依赖 → 需求分析        (点击→表格行1高亮)
                               |  分解自 → (无)
                               | ─ 历史 ─────────────────
                               |  v3 李四 修改预算 12:01
```

- W-3.1 选择联动协议 = SelectionRef{entityType, entityId, fieldCode?};表格行点击→发布选择事件→详情面板 100ms 内刷新(8.4.1);详情面板内点击关系端点→反向高亮表格对应行,若该行未加载则提供「定位」按钮显式跳转(8.4.1 显式定位,1s 内)。
- W-3.2 **选择是纯前端态**:不发任何写请求、不写 storage(AG-209/AG-102);切换工作空间即清空。
- W-3.3 字段级选中(点详情面板某字段)时,表格对应单元格描边高亮——为阶段6 文档视图的属性级联动预留同一协议。

## 4. 版本冲突合并弹层(CF)— 契约 §5.3 响应的 1:1 映射

```
+----------- 字段已被他人修改 ------------------+
| 预算(万)                                      |
|   你的值: 8.5        当前值: 9.0              |
|   修改人: 王五       时间: 12:02:55           |
|   ( ) 采用我的值(基于 v4 重新提交)            |
|   (•) 采用当前值(放弃我的修改)                |
+--------------------[确认]-[取消]-------------+
```

- W-4.1 触发:KERNEL-409-VERSION-CONFLICT;弹层内容直接取 details.conflictingFields(yourValue/currentValue/changedBy/changedAt),多字段冲突时逐字段一行,可逐项选择。
- W-4.2 「采用我的值」= 以响应中的 currentVersion 作为新 expectedFieldVersion 重提;「采用当前值」= 丢弃本地编辑并刷新单元格。禁止出现"强制覆盖"按钮(无视版本的写入不存在于契约)。
- W-4.3 弹层期间单元格保持红框锁定,防止二次编辑叠加。

## 5. 错误与文案(ER)

- W-5.1 错误码→业务语言映射表由前端维护(数据源 error-codes.yaml 的 title/responseRequirement),**禁止**向用户透出 KERNEL-xxx 原码与堆栈(AG-312、9.2.1 前台业务语言);开发模式下控制台保留原码。
- W-5.2 错误分级呈现:字段级(单元格黄/红框)/ 操作级(toast,如权限不足)/ 系统级(状态栏红点 + 可展开抽屉看明细)。
- W-5.3 幂等重放(idempotentReplay=true)对用户**静默**——视为成功,不弹任何提示。
