# 评审命令契约 v1.0（addendum）

- 性质：登记评审域（数据审阅与评价）命令；独立于 M1 内核命令集（AG-301）。
- 端点：命令 `POST /workspaces/{id}/review/commands`；查询 `GET /workspaces/{id}/annotations?targetType=&targetId=&fieldCode=`
- 信封：`{ commandType, workspaceId, correlationId, idempotencyKey, payload }`
- Schema：`contracts/schemas/review-commands.schema.json`（已纳入 `pnpm contracts:check`）
- 蓝本：`docs/06-review-model.md`
- 红线：评审组**不得写主数据、不得调 M1 写命令、不得 import kernel/internal**（AG-101/110 精神延伸）；AG-321 审计

## 命令清单（批1）

| commandType | 语义 |
|---|---|
| CreateAnnotation | 建三级锚定批注（object/field/relation） |
| ResolveAnnotation | open → resolved |
| ReopenAnnotation | resolved\|wontfix → open |

> 回复线程、评审轮次管理、评审域事件入 Outbox、失锚计算接通读模型 → 批2。

## 详规

### CreateAnnotation
- payload：`targetType(object|field|relation)`、`targetId(uuid)`、`fieldCode?(仅 field 级)`、`anchoredDataVersion(integer≥1)`、`severity(info|suggest|issue|block)`、`body(1..4000)`、`roundId?`
- 校验：目标不存在 → `REVIEW-404-TARGET-NOT-FOUND`（经 kernel/api 只读校验）；field 级缺 fieldCode → `REVIEW-422-FIELD-CODE-REQUIRED`；object/relation 级传 fieldCode → `REVIEW-400-SCHEMA-INVALID`
- 锚定：`anchoredDataVersion` 由客户端传入（其所见目标版本），原样固化用于失锚判定；批1 不计算 stale（接通读模型属批2/阶段5）
- 初态：`status=open`

### ResolveAnnotation / ReopenAnnotation
- payload：`annotationId(uuid)`、`comment?(≤2000)`
- 状态机：Resolve 仅 `open→resolved`；Reopen `resolved|wontfix→open`；非法迁移 → `REVIEW-409-INVALID-STATE-TRANSITION`
- **隔离断言**：处理事务内零主数据写（目标对象/字段/关系 version 不变）

## 查询
按 `(workspace, targetType, targetId, fieldCode?)` 返回批注列表，含 `anchoredDataVersion / status / severity / body / createdBy / createdAt`。

## 错误码（前缀决策：新增 REVIEW-，见 AGENTS.md AG-311 修订）
`REVIEW-404-TARGET-NOT-FOUND`、`REVIEW-422-FIELD-CODE-REQUIRED`、`REVIEW-400-SCHEMA-INVALID`、`REVIEW-409-INVALID-STATE-TRANSITION`。
