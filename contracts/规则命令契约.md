# 规则 DSL 命令契约 v1.0（addendum）

- 性质：对《数据内核命令与事件正式契约 v1.1》的**附录扩展**,登记规则 DSL 授权命令与检查结果;不改既有 M1/M2 命令集（AG-301）。蓝本 `docs/14-rule-dsl.md`。
- 端点建议：`POST /workspaces/{id}/rule-commands`（或复用 `/meta-commands`,实现卡定）。
- Schema：`contracts/schemas/rule-commands.schema.json`、`contracts/schemas/rule-result.schema.json`（Draft 2020-12,纳入 `pnpm contracts:check`）。
- 红线：AG-105（规则只读不写主数据）、AG-109/201（不跑重任务、事务内零出站）、8.5（热路径不全量）。

## 命令清单

| commandType | 语义 | 幂等键建议 |
|---|---|---|
| DefineRule | 建/改规则（draft） | `define-rule-<ruleCode>-<n>` |
| PublishRule | 发布锁版（不可变） | `publish-rule-<ruleCode>-<n>` |
| RunRuleCheck | 触发冷路径全量检查 | `run-rule-check-<scope>-<n>` |

## DefineRule

- payload：`ruleCode`、`scope{objectTypeCode[,fieldCode]}`、`severity(BLOCK|WARN|INFO)`、`when(布尔表达式,≤2000)`、`message(模板)`、`lightweight(bool)`、可选 `impact/suggest/fix/templateVersionId`。
- `fix` **仅声明,引擎永不执行**。
- scope 解析复用泛化阶段的子孙闭包:命中 `objectTypeCode` 及其**所有子类型**。引用未发布/不存在类型 → `RULE-422-SCOPE-UNRESOLVED`。
- `when` 解析失败 → `RULE-400-DSL-SYNTAX-INVALID`(返回位置)。
- 已发布规则版本再 Define → `RULE-409-PUBLISHED-IMMUTABLE`。

## 表达式 DSL（封闭集,实现卡详规）

- 语法:字面量、`field('code')`、比较 `== != < <= > >=`、逻辑 `&& || !`、括号。**无赋值/循环/lambda/反射/eval**。
- 函数白名单:`isBlank/length/matches/toNumber/inSet/coalesce`(标量);`relationCount/hasRelation`(有界关系,超限降级冷路径)。
- 沙箱:只读注入"当前对象字段值 + 类型元信息 + 有界关系计数";无写句柄、无 IO;AST 深度与求值步数有上限,超限 → `RULE-422-EVAL-LIMIT`。

## 热路径 / 冷路径（8.5）

- 热路径(命令预检):仅跑"被改对象类型 + lightweight" 规则,对单对象求值。BLOCK 命中 → `RULE-422-RULE-VIOLATION`(返回命中规则清单),事务不提交、无 outbox(AG-201);WARN/INFO 随响应回带。
- 冷路径(RunRuleCheck,worker):全量匹配规则,写 `check_result`(派生输出,非主数据),记 `configHash`;无 sleep（AG-504）。

## 检查结果（rule-result schema）

`{ ruleCode, severity, message, [objectId], [fieldCode], [runId], [configHash] }`。热路径违例项与冷路径 `check_result` 行共用此结构。查询端点 `/views/check-results` 有界分页（AG-202/203）。

## 错误码（登记于 error-codes.yaml）
`RULE-422-RULE-VIOLATION`、`RULE-422-SCOPE-UNRESOLVED`、`RULE-400-DSL-SYNTAX-INVALID`、`RULE-422-EVAL-LIMIT`、`RULE-409-PUBLISHED-IMMUTABLE`（既有通配 `RULE-422-*` 保留为兜底）。

## Schema fixtures
rule-commands 正例:`define-rule`、`publish-rule`、`run-rule-check`;反例:`define-rule-bad-severity`、`define-rule-missing-when`。
rule-result 正例:`violation`、`check-result`;反例:`violation-bad-severity`、`violation-missing-message`。
