# 元模型(M2)授权命令契约 v1.0（addendum）

- 性质：对《数据内核命令与事件正式契约 v1.1》的**附录扩展**，登记 M2 类型授权命令；不改 v1.1 既有 M1 命令集（AG-301）。
- 端点：`POST /workspaces/{id}/meta-commands`（与 M1 `/commands` 分离，保持 M1 注册集纯净）
- 信封：`{ commandType, workspaceId, correlationId, idempotencyKey, payload }`（同 v1.1 信封风格）
- Schema：`contracts/schemas/meta-commands.schema.json`（Draft 2020-12，已纳入 `pnpm contracts:check`）
- 蓝本：`docs/04-metamodel-m2-design.md`
- 红线：AG-109（模板组不跑重任务）、AG-110/201（命令入口、事务内零出站）、AG-321（审计字段）

## 命令清单（批1）

| commandType | 语义 | 幂等键建议 |
|---|---|---|
| DefineObjectType | 建/改对象类型 | `define-ot-<code>-<n>` |
| DefineFieldDef | 建/改属性定义（含 dataType+constraints） | `define-fd-<code>-<n>` |
| DefineRelationType | 建/改关系类型 | `define-rt-<code>-<n>` |

> 发布/实例化/兼容校验（PublishTemplateVersion / InstantiateWorkspace / ApplyTemplateVersion）属批2，另行 addendum，本契约不含。

## 详规

### DefineObjectType
- payload：`templateVersionId?(uuid,可空)`、`code(snake_case,1..128)`、`name(1..256)`
- 校验：`(workspace, code)` 唯一；`templateVersionId` 非空且其状态为 published → 拒 `KERNEL-409-TEMPLATE-VERSION-IMMUTABLE`
- 事件：批1 不发元模型事件（进 Outbox 属批2）

### DefineFieldDef
- payload：`objectTypeId(uuid)`、`code`、`name`、`dataType(枚举)`、`required(bool,默认 false)`、`constraints(object)`
- dataType 封闭集：`string|text|integer|number|boolean|date|datetime|enum|ref|json`（集外 → `KERNEL-400-SCHEMA-INVALID`）
- 校验：归属对象类型不存在 → `KERNEL-404-TYPE-NOT-FOUND`；约束与类型不相容（enum 无 enumValues、ref 无 refObjectTypeCode 或其指向类型不存在、number 的 min>max、pattern 超长/危险）→ `KERNEL-422-FIELD-CONSTRAINT-INVALID`（details 列违例）

### DefineRelationType
- payload：`code`、`name?`、`sourceTypeId`、`targetTypeId`、`direction(directed|undirected)`、`cardinality(one_to_one|one_to_many|many_to_many)`、`semantics(weak|strong)`、`hierarchical(bool,默认 false)`
- 校验：`(workspace, code)` 唯一；source/target 类型存在（否则 `KERNEL-404-TYPE-NOT-FOUND`）；`hierarchical=true` 必须 `cardinality=one_to_many`（承 V2 约束）→ 否则 `KERNEL-422-FIELD-CONSTRAINT-INVALID`

## 类型校验挂点（M1 写命令）
DefineFieldDef 落地的 `dataType+constraints` 由 `FieldValidator` 在 CreateObject/UpdateFields 预检中执行：类型不匹配/必填缺失/越界/越长/非枚举/不匹配 pattern/ref 指向不存在对象 → `KERNEL-422-FIELD-VALUE-INVALID`（details 逐违例字段）。校验在事务预检内完成、零出站（AG-201）。

## 错误码（登记于 error-codes.yaml）
`KERNEL-409-TEMPLATE-VERSION-IMMUTABLE`、`KERNEL-422-FIELD-CONSTRAINT-INVALID`、`KERNEL-422-FIELD-VALUE-INVALID`（复用既有 `KERNEL-400-SCHEMA-INVALID`、`KERNEL-404-TYPE-NOT-FOUND`、`KERNEL-409-IDEMPOTENCY-CONFLICT`）。
