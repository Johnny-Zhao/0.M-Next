## 范围与定位

仿真是 **server 端异步能力引擎请求**(非内核 M1 命令,不改主数据)。`SimulationEngine` 接收**不可变快照**(snapshotId,AG-208)+ 配置,产出结果;一次仿真为一条 `simulation_run`,其状态机到达 `COMPLETED` 即语义上的 **`SimulationCompleted`**。

> **MVP 落地深度(②a)**:`SimulationCompleted` 先落 `simulation_run` 表(状态 + 结果哈希 + 配置快照),**可查询**;发布到 Outbox/RabbitMQ + 读模型投影**后续**(它非内核聚合事件,本期不入 event_outbox)。本契约**登记事件类型与载荷 schema**,供后续总线发布与跨订阅方对齐。

## 1. simulation_run 状态机

`QUEUED → RUNNING → COMPLETED | FAILED | CANCELLED`;非法迁移 → `SIM-409-INVALID-STATE-TRANSITION`。状态变更填 `created_by`(认证上下文,AG-321)。

## 3. 错误码(新前缀 SIM-,登记 error-codes.yaml + AGENTS.md AG-311)

| code | httpStatus | 含义 |
|---|---|---|
| `SIM-404-SNAPSHOT-NOT-FOUND` | 404 | 输入 snapshotId 不存在 |
| `SIM-422-ENGINE-NOT-FOUND` | 422 | engineId 未注册 |
| `SIM-409-INVALID-STATE-TRANSITION` | 409 | run 状态机非法迁移 |
| `SIM-500-ENGINE-FAILED` | 500 | 引擎执行抛错(run 置 FAILED,记 failureReason) |
