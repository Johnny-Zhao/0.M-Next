# 导入命令契约 v1.0(addendum)

- 范围:Excel `.xlsx` 导入 MVP,按用户提交的 ImportMapping 将行转换为新增对象。
- 登记端点:`POST /workspaces/{id}/imports`,支持 octet-stream 与 multipart。
- 元数据端点:`GET /workspaces/{id}/imports/{importId}/metadata`。
- 解析入库端点:`POST /workspaces/{id}/imports/{importId}/parse`。
- Schema:`contracts/schemas/import-mapping.schema.json`。

## ImportMapping

- `sheet`:sheet 名称或 0-based index。
- `headerRow`:0-based 表头行,默认 0。
- `objectTypeCode`:目标对象类型 code。
- `columns`:列映射,每项用 `header` 或 `colIndex` 定位列,并指定 `fieldDefCode`。
- `keyColumn`:可选,用于生成导入行外部 key;MVP 不执行 upsert。

## import_task 状态

| status | 语义 |
|---|---|
| REGISTERED | 文件 blob 已存储,尚未解析入库 |
| PARSED | 预留状态,MVP 不使用 |
| IMPORTED | 已按命令入口完成导入并写入 result |
| FAILED | 解析失败并写入错误 result |

## 端点语义

- 登记只校验 `.xlsx` 类型与 50MB 上限,写入 `import_task` 与 blob,不解析内容。
- metadata 只浅解析 sheet、headers、rowCount,不写主数据。
- parse 调用 ExcelImportAdapter 生成 DataSet,再逐行调用 `KernelCommandService.createObject`。
- 已 IMPORTED 的任务重复 parse 返回原 result,不重复创建对象。
- 行级命令失败计入 `result.errors`;其余行继续导入。

## 错误码

- `IMPORT-400-SCHEMA-INVALID`:ImportMapping 结构无效。
- `IMPORT-404-TASK-NOT-FOUND`:导入任务不存在。
- `IMPORT-409-INVALID-STATE`:任务状态不允许解析。
- `IMPORT-413-TOO-LARGE`:文件超过 50MB。
- `IMPORT-415-UNSUPPORTED-TYPE`:文件类型不是 `.xlsx`。
- `IMPORT-422-PARSE-FAILED`:Excel 解析或映射失败。
